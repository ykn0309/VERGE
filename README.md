# VERGE

Verified Experience-guided Rubric Generation.

方法设计见 [`docs/设计方案.md`](docs/设计方案.md)，工程设计见 [`docs/工程设计.md`](docs/工程设计.md)。

## 环境

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 目录

```text
configs/default.yaml   默认实验配置
verge/
  models.py            领域数据结构
  config.py            配置加载
  dataset.py           数据集读取
  llm.py               LLM 调用接口
  prompts.py           Prompt 定义
  calculator.py        确定性计算
  modules.py           方法模块
  memory.py            Memory 与 trajectory 存储
  pipeline.py          流程编排
  cli.py               实验运行入口
  web.py               本地只读日志可视化服务
  web_assets/           页面资源
tests/                 测试
docs/                  设计文档
```

## 查看运行日志

在运行完成后（也支持运行中查看已有记录），启动本地只读页面：

```bash
python -m verge.web --runs-dir runs --port 8765
# 或指定启动时默认选中的运行目录（同级目录仍可在页面中切换）：
python -m verge.web --run-dir runs/<运行目录> --port 8765
```

在浏览器打开 `http://127.0.0.1:8765/`，通过顶部下拉框切换指定目录下的运行日志（仅扫描含 `run_manifest.json` 的直接子目录，无须重启服务）；切换时样本和经验池同时更新。顶部「收起侧栏 / 显示侧栏」可切换导航宽度，选择会保存在本地浏览器。样本索引使用独立的训练/测试分页，各页单独搜索和筛选结果；无可靠 split 信息的轨迹单列为「未标注」。较长的召回列表、Chosen/Rejected 回答和初始/修订 Rubric 可独立滚动；样本页与经验池页直接显示内容，不再重复顶部页面标题；样本详情不显示流水线状态条或模型请求卡片。经验名称是从内容生成的摘要，悬浮或聚焦可预览完整内容与适用条件，点击查看证据演化。可查看概览（包括已保存轨迹中的候选经验总数、新增/合并/未入池数量）、各样本召回→Rubric→判断→修订→反思→入池流水线，以及经验池置信度/证据演化；初始先验关联入池样本，但先验本身不计入样本信用。页面每次刷新读取最新 JSONL 和快照；未写入轨迹的中断请求会单列显示。经验时间线依据证据顺序重建，并非真实时间戳；内存仅保存当前规范经验和可靠性证据，不保存历次完整内容版本。训练/测试及任务正文只在原始数据文件与 manifest 哈希匹配时展示。样本详情顶部有「流水线」及每个 LLM 角色各自的 Tab，切换后查看该角色每次实际调用的输入、模型原始输出、解析结果及失败重试；展示的是当时的真实角色投影和消息，而非从最终轨迹推测的提示词。新运行会把原始 I/O 写入 `artifacts/role_io.jsonl`（仅本机文件权限 0600，包含完整任务与偏好对，不含鉴权头/API key）；网页按需加载选中样本，不把全量原始消息放进概览响应；单样本页面最多展示前 256 次角色调用，超过 1 GiB 的原始日志不通过网页读取。旧运行若无该文件，页面明确提示无法还原；续跑会复制原文件及哈希，旧前缀缺失时不会补造。请勿共享这份原始日志。Task、Chosen、Rejected 默认展开，各有「翻译成中文 / 显示原文」按钮。翻译仅在点击时使用 Apple 设备端 Translation 框架，不调用实验模型或上传文本；需 macOS 26+、Swift 命令行工具，并预先在「系统设置 → 通用 → 语言与地区 → 翻译语言」安装原文语言和简体中文语言包。首次点击会编译本地桥接程序，稍慢；未安装语言包或系统不支持时页面会显示错误，原文仍可查看。只监听本机回环地址，不提供修改接口；日志可能包含敏感信息，请勿将端口暴露至公网。
