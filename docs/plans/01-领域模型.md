## 目标

在 `verge/models.py` 中建立 VERGE V1 的统一数据契约，为 Calculator、Modules、Memory 和 Pipeline 提供稳定输入输出。

- 必要时更新 `requirements.txt`

- `Criterion`

- `RubricJudgment`
- `RevisionOperation`（生成意图与执行后快照共用）
- `CandidateExperience`
- `TrajectoryRecord`

## 约束

- `importance_score` 是 1–10 整数；
- operation type 只允许 `ADD`、`DELETE`、`MODIFY`；
- 所有实体 ID 显式保存；
- normalized weight、margin 和 credit 不写回原始 criterion；
- 对象支持 JSON 序列化与反序列化；
- 保持模型简单，不引入 ORM 或数据库模型。
