## 实现内容

- 加载 YAML 配置；
- 校验必要字段和数值范围；
- 从 JSONL 逐条读取 `PreferenceSample`；
- 处理 `sample_id`、`task`、`chosen`、`rejected` 字段；
- 支持随机种子和输出目录配置；
- 为非法配置和样本提供明确错误。

JSONL Adapter 使用 `JsonlDataset(paths={"train": "data/train.jsonl"}, field_map={...})`：`paths` 按 split 定位文件；`field_map` 可将标准字段映射到原数据列。配置片段示例：

```yaml
dataset:
  implementation: jsonl
  config:
    paths: {train: data/train.jsonl}
    field_map: {sample_id: id, task: prompt, chosen: winner, rejected: loser}
```

四个主字段必填、`metadata` 可选；空行跳过，重复 ID 在同一 split 内报错。输入路径按当前工作目录解释，不在配置加载时创建目录或读取数据。
