## 目标

用简单本地文件保存 Experience Memory 和 trajectory，在各阶段得到确定结果后直接写入。

## 修改范围

- `verge/memory.py`
- `tests/test_memory.py`

## 实现内容

- JSON 格式 Experience Memory；
- JSONL trajectory log；
- 初始 rubric 判断后直接写入 downstream update；
- Admission PASS 后在 Fusion 阶段写入 ADD / MERGE。

## 约束

- Vector Index 暂不使用远程服务；
- 不引入数据库或 ORM；
- V1 不处理崩溃恢复、重复运行去重或跨文件原子性。

## 测试

- 新建和加载 memory；
- ADD 与 MERGE；
- downstream Beta update；
- 各阶段的即时记忆变更写入；
- 序列化后状态一致。

## 完成标准

- Memory 的 evidence 保留来源 `sample_id`；
- Trajectory 保存主要阶段结果；
- 正常运行的 ADD、MERGE 和 downstream update 可持久化；后续阶段失败时已写入的更新不回滚；
- 测试全部通过。

## 完成记录

- `verge/memory.py` 提供本地 JSON `ExperienceMemory`：按样本写入 downstream Beta 更新，Admission PASS 后根据外部 Fusion 判断即时 ADD / MERGE；零信用保留来源但不记零 evidence，revision credit 不重复乘样本权重。
- `TrajectoryLog` 逐条追加 JSONL，并支持读取全部记录及按 sample ID 查看最后一条；不去重、不回滚。
- `ExperienceMemory(read_only=True)` 用于冻结已有经验；查询返回独立副本，避免绕过持久化改动。
- `tests/test_memory.py` 覆盖创建/加载、ADD/MERGE、来源与证据、即时写入、冻结和序列化。`python3 -m pytest -q`：77 passed。
