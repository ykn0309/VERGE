## 目标

用简单本地文件实现 Experience Memory、trajectory、pending changes 和幂等 Commit。

## 修改范围

- `verge/memory.py`
- `tests/test_memory.py`

## 实现内容

- JSON 格式 Experience Memory；
- JSONL trajectory log；
- pending memory changes；
- sample-level 原子 Commit；
- evidence 唯一键检查；
- committed sample 跳过；
- 未提交 sample 恢复；
- ADD、MERGE 和 downstream update。

## 约束

- 中途失败不得部分更新 Experience Memory；
- 同一 evidence 不得重复写入；
- Vector Index 暂不使用远程服务；
- 不引入数据库或 ORM；
- 文件写入使用临时文件加原子替换。

## 测试

- 新建和加载 memory；
- ADD 与 MERGE；
- downstream Beta update；
- 重复 evidence；
- Commit 中断；
- retry/resume；
- 序列化后状态一致。

## 完成标准

- sample 只能成功 Commit 一次；
- Memory 更新均可追溯到 sample；
- 中断后可以安全恢复或重跑；
- 测试全部通过。
