# 经验单候选与下游验证

## 决策

每次成功修订最多提炼一条最有迁移价值的单一机制；没有合适机制则为零。候选模型只返回 content、trigger。取消操作绑定、修订收益、预算及信用分配的运行步骤和模块装配。准入直接审核候选。

ADD 初始化 Beta(1,1)，置信度 0.5、无信用证据；MERGE 保持 canonical 文本和所有 Beta/证据，仅追加来源。修订成功、生成、准入、合并不增加信用；信用仅由后续训练任务 R0 来源标准贡献更新。测试仍只读冻结。

Web 删除绑定/暂定信用展示和信用失败分支，候选显示准入及融合；证据指标及候选演化只反映下游反馈和不计信用的融合。

旧暂停实验保持原样，不允许跨提示词版本恢复到新方法。历史领域字段保留供只读日志解码，当前固定 links=[]、credit=null、operation_contributions={}；已删除运行阶段和信用配置。

## 验收

覆盖 0/1/多候选边界、拒绝模型信用/绑定字段、中性先验、合并保持已积累下游信用、准入失败、错误继续及 Web 状态。未启动真实新实验。

验收结果：完整离线测试 328 项通过；JavaScript 语法及 git diff --check 通过。旧信用分配测试已替换为单候选、中性先验、下游更新和融合状态不变的测试；代码尚未提交，未发起真实模型请求。
