# 仅生成与修订实验开关

## 授权范围

准备阶段用户选择“只实现并准备配置”，当时未发起真实实验、未下载数据、未提交。随后用户明确授权“提交代码然后开始实验”：先提交已验证实现，再从新目录运行100条；数据、模型与两轮修订参数保持不变，完成后复核修订成功与失败原因。

## 配置与语义

新增 `run.experience_enabled`（Boolean，缺省true），与training独立：false时训练仍执行Generator→Judge，失败后最多两轮Critic→Generator→Judge；但完全跳过Retrieval、Selection、已有经验信用、Reflector、Admission、Fusion及弱证据计算/写入。Generator的所选经验与R0来源均为空。保持最近有效基线、无效修订隔离、程序接管修订来源及原始日志。

已有组件配置继续保留并校验，不放宽秘密字段/组件校验。未使用的经验角色对象不会执行；vector检索关闭时不构造embedding客户端。保留空经验池文件仅供审计及Web兼容，不进行样本级经验读写。Runner的禁用模式即使注入非空/只读经验池也不读取、应用或改写它。

新增可选 `run.stop_after_train`（正整数）：无CLI限制时使用配置限制，显式`--stop-after-train`优先。限制是绝对已处理训练前缀，包含样本错误，暂停时不进入test；不裁剪/复制数据集。

测试/held-out保持initial-only；关闭经验时测试也不检索/选择，并行worker继承开关，不能偷偷恢复经验调用。模式与有效样本限制写入manifest，默认全流程行为不变，resume仍按配置与源码指纹保护。
