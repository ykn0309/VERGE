# Web UI可读性与布局优化

用户依据样本2936的截图要求优化Web UI。本轮只修改`verge/web_assets/app.js`和`style.css`；保留实际轨迹、消息、方法参数与Python代码。与计划32启动快照比对，Python源码指纹完全一致。

## 已落实

- 统一系统字体、浅色背景、深色导航、留白和状态色；收窄导航与列表，为右侧详情留出空间。
- 列表使用子集与样本编号，任务文字归一化空白并限制两行，不让长文本/换行撑开列表；候选计数取保留轨迹，含重生成，不沿用最后一次Critic回复的单次计数。
- 样本页新增流程状态条，分别标注已完成、未通过/缺有效结果及未进入；编号分段展示输入、固定E、R0及应用轮。
- 任务占整行；足够宽时chosen/rejected并排。小屏自动单列。回答各自滚动，保留翻译入口；本轮浏览器验证未发送翻译请求。
- Margin和两侧分数集中展示；criterion用“标准1”等可读编号，完整ID可展开。C/R有标签说明。
- 候选正文、适用条件、准入理由分别成块。准入理由默认摘要、可展开全文；Critic/Generator私有分析和原始快照默认折叠。
- 经验池和候选列表使用正文摘要；规范ID保留副行/提示。经验页保留文本版本、双通道与演化时间线。
- 重整CSS，移除旧布局重复覆盖；概览、角色消息、弹窗、移动布局保持同一视觉规范。
