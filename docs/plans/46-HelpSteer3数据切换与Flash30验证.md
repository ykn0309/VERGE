## 内容复核与主要发现

### 数据信号更容易解释，但强一致标签仍不是事实认证

例如8945非优选仅列关键词而未给产品描述、18882建议全部保留VHS而未帮助缩减、19972只复述写故事的指令。此类差异清晰。13725、19944、15908等则仍存在双方都覆盖主要要求、图像均不足、主要风格偏好的情况。人工理由有助于定位差异与标签疑点，但没有作为运行监督输入。

首30条创作/角色任务较多，不代表General总体，更不代表Code/STEM/Multilingual；不能将本轮四条经验视为全领域经验库。

### 任务以外的要求仍会主导标准

13725任务仅要求同时验证自己和他人感受，R0却要求“结合而非割裂”；Critic识别了隐性高阶要求，却继续把“至少一个整合场景”写成必需经验，R1/R2该项权重0.5/0.6，两侧都失败，最终平分。两轮trigger依赖已有标准或回答表现，不能事前直接适用。

21600明确要求非常简短的跨界背景，Generator/经验却强化角色数值、具体行为、通过情节展示特质等，忽略“简短”在主次取舍中的作用；两轮最后全false。事实和条件核验的细化不能自动代表合理标准。

25709 R0以“是否包含比较表达/排名”这种缺陷问法按是加分，偏离当前正向问题契约；Judge又将“不比较”的劝阻语言与执行比较混淆。R1改为正向避免比较，两侧均true；R2重新出现主动比较的缺陷问法，两侧均false/false，仍平分。提示词约束没有保证实际语义极性正确，程序只能检查字段与计算。

### 四条入池经验及实际证据

| 来源 | 经验方法 | 应用margin | 候选P / N | 复核 |
|---|---|---:|---|---|
| 22258 | 多角色命名的相关性与解释，替代绝对专属要求 | 0.5 | 0.35 / 0 | method部分合理；trigger依赖当前标准导致全低分，含2099等源场景说明 |
| 20767 | 角色语言特征服从具体情境，扩展身份表现方式 | 0.25 | 0.25 / 0 | R0虚构魔法少女背景；R2减少限制，成功主要来自不把幼儿交给伤者 |
| 22317 | 区分事实复述和推测，核验施受关系与时间条件 | 0.1 | 0.3 / 0.2 | 施受关系核验有价值；保留出租车/假期具体例子，容易把主观报告当客观事实 |
| 15908 | 风格关键词通过语境表达而非密集罗列 | 0.65 | 0.65 / 0 | 区分自然表达与堆词，但把所有并列形容词都判不满足过严；trigger需先看回答 |

所有ADD保存实际候选原文。22317的alpha=1.3、beta=1.2、confidence=0.52，P/N没有先抵消；整体成功不掩盖负信用。其Critic还错误复述初始标准1曾判chosen不满足，实际该项true/true，说明依据传递正确仍不能保证分析忠实。

20767的经验获得10897、19707、19079、21600四条R0下游信用（P分别0.2、0.2、0.25、0.1），alpha累计2、beta1、confidence=2/3。其中21600总体R0失败，仍按实际引用项保留P。其余入池经验尚无下游数值证据。

这些后续采用也暴露错误泛化：10897只是人物介绍，E引入了对话风格、现实情境、互动场景等未要求条件；19707关于心灵感应的task本身就有明确依据，来源是否体现实质新增设计仍是模型自报；19079奖励长扩写、21600忽略简短要求的风险仍在。下游P反映当前标准与Judge的应用表现，不证明这些经验整体正确或造成成功。
