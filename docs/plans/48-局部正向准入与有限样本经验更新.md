## 1. 已确认规则

- 对经验e，仅按引用它的标准计算P/N，使用既有归一化权重和多来源均分。净正向定义为P>N，与整个rubric的margin无关。
- 候选实际提供、被引用、Judge完整有效且自身P>N即可入池；整体失败不再阻止准入。整体成功但候选P≤N不入池。
- 合格候选先暂存，样本正常结束时最多选一条新增；两轮都合格时优先C2，否则回退C1。取消Fusion模型调用及跨经验MERGE。
- 已有经验在训练R0中实际采用且自身P>N时，可收录新样本并触发文本更新；不要求整体成功。R1/R2已有E仍只审计，不重复记账或触发文本更新。
- Beta仍alpha+=P、beta+=N，不先抵消、不折扣。P>N仅控制准入/文本更新，不能用净值替代数值记账。未引用或P=N=0不增加信用。
- 每条经验的归纳集合最多10个不同sample_id，包含最初来源样本；同题多个轮次不占多个名额。集合满10条后冻结文本，后续仅累计信用及使用日志。
- Critic保持计划47的样本内多轮消息；Generator保持每轮独立task+固定E+当前C。模型仍固定Qwen3.5-Flash、关闭思考。

## 2. 候选准入与业务控制

每次有效应用之后，独立判断整体任务结果和候选准入资格：

| 整体结果 | 候选P>N且被采用 | 行为 |
|---|---|---|
| 成功 | 是 | 暂存合格候选，结束轮次并统一选择入池 |
| 成功 | 否 | 结束轮次，回退之前合格候选（如有） |
| 失败 | 是 | 暂存合格候选；有剩余轮次则Critic继续纠错 |
| 失败 | 否 | 不入池；有剩余轮次则Critic继续纠错 |

首轮合格C1不立即写入Memory。第二轮仍替换当前C，不重新检索E、不叠加C1，Critic保留第一轮分析、候选及实际结果。

整体成功、轮次耗尽或Critic返回空候选等正常结束时统一选择：C2合格则只新增C2；否则C1合格则只新增C1；均不合格则不入池。第二轮格式/结构耗尽也可回退已有合格C1，但不能伪造C2的有效结果。每个样本最多新增一条，新文本保持被选候选实际应用原文，仅写入它对应轮次的P/N，不把两候选信用合并。未选候选完整留轨迹。

优先C2是选择规则，不证明其质量优于C1；不直接比较两轮P−N大小，两轮rubric和权重可能不同。不同题仍可能产生相近经验，同题最多一条不保证整个池去重。

新增独立的候选资格、最终选择与入池记录，不能通过application_success或入池非空推断整体成功。更新Trajectory模型中目前强制Fusion关联整体成功的校验，以及CLI统计、Web和审计；删除旧Fusion字段/角色契约，不兼容旧运行。

Judge错误或角色拒答属于错误结束，不执行候选回退入池；有效C1留轨迹，有效R0仍可更新自身信用/有限案例。基础设施/程序错误fail-fast，不做正常收尾。暂存有效结果必须留档，失败恢复不得重复入池。

P>N资格判定沿用十进制精确比例思路，避免浮点相加把数学上的P=N判成净正向；对外仍记录可读P/N。

## 3. 有限样本重新归纳

新增经验更新LLM职责：接收经验当前content/trigger及完整的有限归纳集合，返回新的content/trigger或明确保持原文。每次重新读取集合，不仅依赖上一版文本，避免串行改写遗忘早期依据。

每份案例保存：

- sample_id、原始task与chosen/rejected；不输入HelpSteer3人工理由或metadata；
- 本次实际使用的经验文本版本；
- 相关阶段的rubric、来源引用、Judge两侧Boolean与reason、整体margin、经验P/N；
- 初次提出来源案例可补充对应Critic分析和候选应用，不传无关角色历史。

ADD首次保存实际应用候选原文及来源案例，不立刻增加一次清理调用。已有经验出现新的净正向R0使用时，按sample_id去重并加入集合；从第2个案例起重新归纳，加入第10个案例时执行最后一次归纳，第11个及以后不再调用文本更新模型。若模型保持原文，新案例仍占一个名额，累计集合不能只统计成功改写次数。

归纳关注跨案例共同设计方法、任务差异和适用边界，把常量转为新task参数，不拼接角色名、情节或样本举例；允许收窄条件、删除缺乏支持的细节，也允许保持原文。结构由程序校验，不新增Admission或额外语义审核门禁。

P≤N的实际使用仍保留完整结果及负向信用，不触发本次文本更新。本版先保留为审计与边界分析证据，不额外把无上限失败样本追加到归纳输入；以后若纳入重新归纳，应从同一有限案例预算中分配，另行明确选择规则。只有正向案例以及前10条的相似性仍可能造成偏差，饱和不意味着经验已足够通用。

10条限制的是案例数，不自动限制token。使用固定字段投影省去无关轨迹，案例内容不静默截断；调用前检查完整system/user UTF-8文本预算100,000字节。超预算记录未完成更新并保留旧文本，不伪造新版本；网络/鉴权错误继续fail-fast，格式/结构纠错有限。
