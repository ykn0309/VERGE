# 计划54：Critic证据表达与Generator定向示例复测

用户授权分别修改提示词做独立小规模复测，检查Critic证据误读的可能原因；Generator优先测试计划53准备的原创定向示例。任务覆盖问题不作为本轮专项，不测试相关旧案例；Selector/Judge仅保留计划53纠错示例，不加入生产提示词。

固定Qwen3.5-Flash、关闭思考。Generator三个真实输入（虚构时代限制、条件前提/角色信息、正常双主体方法）各跑当前版与两个定向示例版，共6个输出。Critic五个真实输入来自四个独立任务，含同题第一轮与真实第二轮历史、视频读听、自我/他人感受、故事对照；各跑原版、仅分栏、仅A/B标签、仅原文核对提醒、组合版，共25个输出。预定31个输出；每次沿用最多三次后端尝试和最多三次结构尝试，基础设施错误fail-fast，不追加无限测试。

Critic原版user及真实assistant历史逐字保留；分栏版只把每条标准的两侧Boolean和原始理由组织为各自小块。标签版改为回答A/B并明确chosen/rejected映射，保留原始任务、回答、理由及上一轮assistant；原文核对版只追加简短system提醒。组合版不能单独归因于排版或标签。

脚本：[replay_role_prompt_ablation.py](../../scripts/replay_role_prompt_ablation.py)。输入与输出、请求/回复、模型及消息指纹、源文件哈希另存到`runs/role-prompt-ablation/`。不更新池、信用、轨迹，不运行完整流水线，不重启Web，不改变生产提示词。语义复核覆盖两侧身份、实际判定、引用归属、无依据要求、公开经验泛化与正常行为；结构合法不视为成功，空候选也不能掩盖错误诊断。单次固定输入结果不能证明跨任务稳定性、整体准确率或模型内部原因。
