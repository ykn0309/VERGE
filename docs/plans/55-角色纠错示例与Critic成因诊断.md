# 计划55：角色纠错示例与Critic成因诊断

2026-10-13，用户询问分栏是否改善、偏好标签如何影响诊断、Generator条件前提错误的出现范围、Selector/Judge修正版是否有效及Critic其他可能原因。沿用独立历史输入，不运行完整流水线、不更换模型、不替换生产提示词。

Selector/Judge复用计划52每角色三个输入，对照当前版与计划53纠错示例，各六个有效输出；正常预算12，Judge一次调用两次结构纠错，实际14请求。Selector两例局部减少误选，仍有无关背景经验被选；Judge计数不稳定，不部署。

Critic四组配对：两题分别保留/删除Judge理由（判定不删）；同题第二轮保留/屏蔽真实首轮analysis（候选及应用反馈保留）；感受题两版都用A/B并删除摘要分数，仅一版提供偏好映射。共八个有效输出、九请求，视频题保留理由版一次格式纠错，因此其对照不是严格只有理由字段差异。均Flash非思考、有限纠错。结果保存原始消息/输出/错误，源哈希核验不变。

Generator只筛查历史100个不同任务R0，其中74条带已有经验；重点复核24条实体存在/存疑方法相关输出。精确的“经验本身指出当前角色不存在”错误仍只在计划54一个独立任务明确复现。其他存在性声明、版本锁定、官方设定要求等属于相似适用性/知识/阅读风险，未逐个确认同因，不统计为同一错误的普遍发生率，不继续专项few-shot优化。

Critic删除理由时人物题发现无依据眼镜，视频题发现读听子问题缺口；但仍有不通用经验和过强要求。屏蔽旧analysis改变了第二轮诊断方向，未证明稳定减少错误；偏好映射配对均为空候选，未验证偏好身份是主要原因。先把Judge理由锚定作为待进一步验证的线索，不能直接得出删理由/删历史有效或断言输入不是主因。

299项离线测试通过，本轮20份有效输出/23请求（2次结构纠错、1次格式纠错，无网络重试）。源产物与生产提示词未改；没有提交/push或Web重启。详细报告见[诊断简报](../实验分析/历史运行归档/critic-evidence-ablation/实验简报.md)，脚本为`scripts/replay_critic_evidence_ablation.py`及原模块few-shot复测脚本。
