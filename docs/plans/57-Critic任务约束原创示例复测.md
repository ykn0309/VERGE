# Critic任务约束原创示例复测

用户授权两条原创few-shot、历史问题/正常输入对照，只复测Critic，有效再写入生产。

示例独立编写：桌面电缆整理展示两答达标、不同方法数量不能成为数量门槛；缺失观测绘图展示任务禁止无依据补全，而当前标准遗漏这一要求，需增加有任务依据的核验。示例的Judge判断均符合现有标准，第二例的错误位于标准遗漏任务约束，不把Judge误判硬转成设计问题。

固定历史trace 163、167、724、4、390、281，6条输入、5题，生成12份当前版/示例版输出。使用当前生产可读布局、中文标签及完整Judge理由，不加入计划56的实验映射说明；第二轮保留真实首轮assistant，新增输出不反馈给后续输入。唯一对照变量是system附加两个教学示例。

Qwen3.5-Flash、关闭思考；沿用backend最多3次有限尝试，不额外扩展预算。原产物/源码/示例哈希冻结，结果另存`runs/critic-grounded-few-shot/results/`，保存准备输入、配置、原始请求/回复、新旧结果及错误；不运行流水线或写经验池。

复核每个案例的task/回答/标准/Judge，检查无依据格式或数量要求、真实遗漏与判定归属、公开方法通用性及trigger是否事前可识别。故事/帐篷的空候选不是金标准，也不把“不提经验”的数量当成功；观察正常行为是否受损。仅有局部改善或新退化时保留候选示例，不写生产；不能据12次复测声明稳定性或整体收益。

实现：`scripts/replay_critic_grounded_few_shot.py`；示例：`runs/critic-grounded-few-shot/examples.json`。

完成：12份结构有效输出/12请求、零重试，303项测试通过，原产物/生产源码/示例/脚本指纹未变。部分诊断改善，但人物题仍加格式禁令、二轮仍误引事实，视频和帐篷新增无依据限制；没有一致净改善，示例保留为候选、不加入生产。详见[简报](../实验分析/历史运行归档/critic-grounded-few-shot/实验简报.md)及[逐例复核](../../runs/critic-grounded-few-shot/results/semantic_review.json)。
