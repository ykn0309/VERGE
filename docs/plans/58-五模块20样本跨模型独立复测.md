# 五模块20样本跨模型独立复测

用户明确要求各模块至少20条有代表性的历史输入，独立测试不同模型，不跑流水线，并授权DEEPSEEK_API_KEY对应DeepSeek V4.1 Flash。该授权覆盖此前AGENTS/记忆中Qwen单模型实验约定；生产配置仍保持。

Selector、Generator、Judge、Critic、Updater各20条历史真实输入，在模块内按任务文本去重；从现存100题运行选取问题、对照及边界任务，逐项记录trace和选择理由。Updater20条是不同归纳输入包（各2–5案例），不同包可能包含共同来源；不将案例重叠算作独立下游泛化。20条不是全任务分布随机样本，无法估计生产错误率。

两模型为Qwen3.5-Flash、DeepSeek V4.1 Flash（官方API名称deepseek-flash），均关闭思考。固定相同当前生产提示词/输入，每模块40份输出，共200；Critic另用同一20条在现有analysis/candidates结构下仅核对事实、空候选，两模型再40份，共240份计划输出。每输出最多3次格式/传输尝试，每项结构错误最多3轮，预算上限2160次请求，不无界补测。最多4个独立进程并行，每进程内部顺序调用；遇基础设施/程序错误按现有有限后端重试后fail-fast中止，不静默换模型。

使用完整task/回答/经验/标准/Judge及真实Critic历史，Generator/Updater明确按计划53当前输入契约转换，Updater案例短编号；无输入截断、额外摘要、检索重算、新输出串联或池写入。Critic20任务含4条真实二轮，两模型均继承原Qwen assistant，单独记录这种历史条件。事实诊断只用于定位问题，不能作为新增生产调用。

冻结选择、输入、配置、提示词、脚本及源产物指纹。保存原输入/历史输出/新输出、实际HTTP JSON请求和原始响应（不保存鉴权头）、重试/错误/耗时/token。产物目录`runs/module-model-replay-20/`，原100题运行只读。

评估：结构有效率及已知真值可核对的Judge项单独统计；语义复核分别检查Selector适用性、Generator任务约束/经验落实、Judge事实范围/数量/否定与依据、Critic事实归属/无依据规则/经验及trigger、Updater共同方法/必要边界/拆分归属。没有独立可靠金标时不以历史输出当标准答案，也不以少选/少提案/少拆分等数量当准确率。输出模型自身analysis不作为真实性证明，不以偏好标签强造标准。

接口依据：[模型名称](https://api-docs.deepseek.com/)、[thinking.type=disabled](https://api-docs.deepseek.com/guides/thinking_mode/)、[JSON输出](https://api-docs.deepseek.com/guides/json_mode/)。2026-10-13实际GET/models已确认deepseek-flash可用。脚本：`scripts/prepare_module_model_replay.py`、`scripts/run_module_model_replay.py`。
