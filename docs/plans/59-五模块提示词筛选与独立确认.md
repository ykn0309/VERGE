# 五模块提示词筛选与独立确认

用户要求保持现有模型，继续独立实验寻找更好的提示词。固定Qwen3.5-Flash、关闭思考，沿用计划58五模块各20条任务去重输入，同时比较当前生产版、精简职责版、精简职责加原创教学示例版，计划300份输出。示例独立编写，不提取或改写数据集案例；只改变system，保留完整输入、短编号、真实Critic历史、输出结构和有限纠错，不增加analysis字段、角色调用或业务审核机制。

实验前另冻结Selector/Generator/Judge/Critic各20条不在筛选任务中的历史输入，以任务长度分层、固定种子59选择，保留实际多轮历史。Updater现存运行只有28个不同最近任务，其中20个已进入筛选，故确认仅使用全部8个剩余任务，不伪称20个新任务。根据筛选阶段语义复核预先选择每模块一个挑战版，再与当前版进行独立确认，新增176份输出、总476份计划输出。确认不是held-out终测；仍来自同一100题历史运行，Updater案例包有来源重叠，不能据此证明泛化或全局最优。无明显收益时保留原版，不以少选经验、少提案、少拆分或格式通过替代正确性。

复核Selector的任务操作/方法适用性，Generator的任务约束/来源/正向问题，Judge的可核对事实及Boolean–reason一致，Critic的事实归属/无依据规则/真实遗漏，Updater的必要动作及范围保留/重复拆分。Judge沿用计划58的46条有限参考，筛选前已固定；其余采用逐案有依据的改进/退化/相当比较，记录具体问题，不假称自动准确率。任务覆盖和条件前提专项仍暂停，不另加专项示例。

最多4进程，单输出保持现有最多3次后端尝试×3次结构纠错；基础设施/程序错误fail-fast。保存冻结选择/全部输入、新旧输出、提示词、模型、实际请求及原始响应，保护源日志/池/轨迹/生产代码与旧实验；鉴权头及API key不落日志。目录`runs/module-prompt-replay-20`和`runs/module-prompt-confirmation-20`，不跑流水线、不写池或替换生产提示词。

脚本：`scripts/prepare_module_prompt_replay.py`、`scripts/run_module_prompt_replay.py`、`scripts/audit_module_prompt_replay.py`。
