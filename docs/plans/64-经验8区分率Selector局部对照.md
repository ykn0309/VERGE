# 64 — 经验8区分率Selector局部对照

用户授权针对被反复引用的经验8，独立测试区分率是否影响Selector选择，不跑完整流水线、不替换模型或上线新规则。

固定200题实验中真实召回该经验的24个不同任务、当时完整候选列表/排序/文本版本、置信度及证据量。对照组复用历史实际消息；实验组仅在同一user消息末尾增加区分率定义和所有候选的历史统计。区分率按R0引用标准计数：正确或反向区分数/全部引用数；不等同正确率，不包含本题、未来、原题候选验证或R1/R2反馈。只有严格前序任务反馈可见，暂无记录为未知；统计与现有置信度一样跨文本版本累计，不能据此证明新版本有效。

选题在请求前冻结：8个缺失上下文/澄清任务、8个创作或已有材料任务、8个边界任务，覆盖原正向/反向/同判及历史未选中案例。这是分析分层，不将分层或Judge方向当作经验适用性的标准答案；对变化案例逐一结合task和经验文本复核，不以少选为改善。

共48个Selector输出，Qwen3.5-Flash、enable_thinking=false，每个最多3次后端请求（HTTP上限144），不增加结构纠错调用。每个输入独立，输出不反馈后续输入，记录实际HTTP请求/回复、原始模型输出、结果/错误、模型配置及源码/来源哈希；不写经验池、信用或原轨迹。一次配对观察只能说明当前输入和指标表达下的行为变化，不能单独证明稳定因果、经验选择质量或下游准确率改善。
