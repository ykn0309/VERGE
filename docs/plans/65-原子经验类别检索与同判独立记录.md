# 原子经验、类别检索与同判独立记录

用户确认后实施：类别只组织，不拥有信用；小经验独立引用、信用、案例和更新。归纳员仅修正当前方法及适用范围，不新增提案/验证分支，不恢复拆分或MERGE。

## 实施范围

- Critic和Updater明确每条经验为一个可独立采用/忽略的核验方法；只靠结构不能保证语义原子性，保留局部复测和人工复核。
- 正确区分记P，反向区分记N；同判仅分别记录双方满足/双方不满足次数，不改Beta、不进入归纳、不占10条额度或3任务窗口。混合案例的归纳输入仅保留有区分的相关标准；完整轨迹仍保留。
- 类别有稳定ID、名称、描述、成员归属，无独立信用。新入池/正文或trigger变化进入持久待整理队列；按不同小经验去重，默认5条可配置，样本结束时整理，运行收尾处理剩余队列。信用变化不触发。
- 整理为一次独立模型调用，读取小经验正文/trigger及现有分类，输出完整分类方案，可保留未分类项。短ID，成员恰好分配一次，不能改变正文/信用。有限纠错失败保留原分类及队列；同一待整理版本不在每题重复调用。
- 检索单位为类别或未分类小经验，Top20单位；类别向量包含名称、描述、全部成员trigger/content。命中后完整展开，Selector一次选择最多5个小经验，不输出类别。成员/类别变化使向量缓存失效。
- 展开后的Selector完整输入设可配置字节预算，超出则记录样本错误，不静默截断类别或再次筛选。区分率不提供给Selector。
- Manifest/Trajectory升级8、Memory升级6；旧产物保留，拒绝跨协议resume，不引入迁移或生产兼容层。Web适配新分类和同判展示，原有排序/滚动行为保留。

## 验证

确定性测试覆盖信用、同判容量/窗口、全量分类原子写入、失败保留/重试、收尾、冻结评估、向量排名/缓存、短ID、完整展开及预算、存储/resume和Web契约。

对修改的Critic/Updater/Selector各固定至少20个去重真实历史任务进行独立复测；新增Organizer用20组独立历史经验快照检验分类。Qwen3.5-Flash非思考，结果另存，不链式应用、不跑完整流水线、不修改原池/轨迹。新增分类输入缺少历史同角色请求，明确记录转换与局限；不宣称语义原子性、整体准确率或检索收益已证明。
