# 计划68：演化信用继承与稳定性惩罚

日期：2026-10-17。状态：实现及局部验证完成，360项离线测试通过。继承计划67的固定文本版本、五案例归纳和局部分类，仅修改演化信用记账。

## 确定规则

- keep、修订后文本完全相同及失败均不惩罚、不产生继承账本。
- replace继承全部历史P/N和此前演化惩罚；split为k条时分别均分这些量，每条仍有独立Beta(1,1)先验。
- 本次惩罚D=0.2×实际触发归纳的最近5个本版本下游案例累计(P+N)，只在成功replace/split时加入子版本beta；拆分时D/k，总额不重复。
- 真实本版本反馈、继承P/N、继承旧惩罚及本次惩罚分别记录。alpha=1+总P，beta=1+总N+总惩罚；证据量只计实际/继承P+N，不把惩罚解释为观测证据。
- 父记录原样保留并退役；子usage/案例窗口仍为空，继承信用不伪装成本版本验证次数。不复制祖先案例或原始反馈事件。
- 新协议Memory8、Manifest/Trajectory10，拒绝旧协议，不加兼容或迁移；不改变角色职责或输出；Selector仅同步置信度/证据量的字段说明，提示词标识更新为immutable-atomic-evolution-inherited-credit-v2。
