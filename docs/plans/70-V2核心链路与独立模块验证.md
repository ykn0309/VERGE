# 70 — V2核心链路与独立模块验证

依据唯一方法规范[设计方案](../设计方案.md)，本计划实现V2基础链路；不执行完整训练或参数估计实验。

## 实施范围

1. 升级经验、单来源标准、应用账本及持久化协议，删除类别、Atomizer和P/N长期信用；直接混合检索，候选Generator仅接收当前C。
2. 接入三个独立Checker及错误优先汇总，保留未知/调用失败差异；实现三状态反馈、参数加载和逐次贝叶斯推断，缺参数时Q保持未估计。
3. 实现每3个新任务检查、最近6任务异常门槛、3+1+1+1案例抽样、Keep/Revise及隔离配对回放；至少3个共同有效任务、新版净区分总分严格更高才替换。
4. 同步CLI、配置、只读WebUI和工程文档。保留旧产物，拒绝旧协议读取及resume；删除旧协议专用测试，历史源码由Git保留，使用V2行为测试替代，基础数据/传输/翻译测试继续运行。

## 验证

- 确定性检查覆盖字段/模板绑定、单来源、比例汇总/抵消、Checker组合、数值稳定性及重算、去重/持久化、版本替换/冻结/失败隔离、直接检索和可见性。
- 从计划69真实历史产物选择至少20个不同任务，明确转换记录。每个修改角色独立运行，Qwen3.5-Flash关闭思考；新输出不传给下一角色、不反馈原池。真实调用预算按有限重试配置执行，原始请求/回复、结构及语义复核结果另存。
- 不运行多模型参数标注、不提供虚构可用概率表、不启动完整训练，不自动提交或推送。
