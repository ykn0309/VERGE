# 74 — WebUI阅读体验

用户要求提升现有本地WebUI可读性。本轮仅修改展示与交互，不改方法、模型提示词、实验数据或后端推断，不触发真实模型调用。

- 保留顶栏三个页面入口；列表提供短编号、中文状态、搜索/筛选，点击和刷新保留位置。
- 样本详情分为任务与回答、评分标准、经验与核对、Critic纠错和调用记录。回答并排、保留段落并支持展开；标准直接展示权重、两侧Boolean和依据；Checker按经验分组显示三类报告和细项，不用原始JSON代替正文。
- 经验详情区分方法、证据与历史应用，来源/下游/回放独立显示；长ID和原始数据仅在元数据/调试展开中出现。
- 深链接支持样本、经验和详情页签；支持上一题/下一题。调用记录按需获取、可按角色筛选，错误和空状态明确。
- 使用纯DOM回归及真实本地浏览器检查概览、样本、标准、核对、纠错、经验和筛选。只修改静态资源，无需重启Web服务。
