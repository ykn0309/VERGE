# 88 — Critic提示词语言、精简与思考对照

只研究Critic，不变更生产提示词或其他模块。固定计划84/87同20个按任务去重的完整历史输入，分别比较：当前英文长版、等义中文长版、保留相同三个原创示范的中文短版。每版均关闭/开启思考各20题，共6组120项角色调用；各组4并发、同样300秒请求超时及网络/结构各最多2次重试，输出不传下游，不写池、不跑完整流水线。

英文长版对中文长版比较指导语言；中文长版对中文短版比较可否精简；每个版本内开关思考比较思考效果。短版是信息压缩，不声称只改变字数而完全不改变强调程度；没有英文短版，不外推所有语言与长度交互。仍使用Qwen3.5-Flash，传入enable_thinking布尔开关，保存请求、输出、提示词、配置、用量、耗时及源哈希。

逐题审阅候选是否举例、残留原题、过度抽象，以及诊断依据、合理性、原子性与适用性。空候选单列，不以全部不提案当质量提升；结构有效单列。预先指定字数误判、偏好当任务要求、背景强制复述、角色视角、法律具体性和语义前提等历史问题作核查，但不把未核验外部专业事实当真值。

本轮不是统计充分的优胜证明，也不使用测试集；120次调用仍只有20个不同任务。生产维持v23，结果与采用建议写入独立报告；必要的重复确认需由比较结果说明理由，不无限搜索。

状态：6组120次调用及逐题内容审阅完成，19项相关离线测试通过。未证明英文/长版稳定优胜，思考开销显著而关键诊断错误仍在；生产未变，详见[报告88](../实验分析/88-Critic语言精简与思考对照.md)。
