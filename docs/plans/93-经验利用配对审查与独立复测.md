# 经验利用问题审查与独立复测

用户授权：审查最近200题冻结实验，Terra子代理并行分析案例，找到共性，提出互斥改进方案独立复测并迭代。只改善经验利用，不重新训练或改测试结果。

## 方法

- 审查34道退化题及改善/双方正确对照，检查原任务与两回答，区分经验缺陷、Selector触发条件错配、Generator假约束/覆盖变化、Judge疑误，不把偏好标签当作标准真值。
- 固定每模块30个按任务去重真实输入：18退化、6改善、6双方正确；另留至少20个不同任务用于迁移检查，开发组上改进不足时继续诊断，留出组不可不断调参。
- 原始历史请求不变，只改变该角色提示词。Selector复用实际候选及质量信息；Generator复用实际选中经验，禁止接收新Selector输出，确保模块独立。若历史输出含模型重试，仅取最终成功的真实输入，保留原始请求及映射。
- 原版与两个候选版本对照；中文简短约束，无新增输出字段/调用；Qwen3.5-Flash关闭思考，每案例独立并行，有限纠错。产物隔离，不写经验池或原日志。
- 内容验收：Selector选择是否有任务前提依据、是否遗漏适用方法；Generator是否增添任务外限制、误把条件当事实、遗漏核心要求、是否合理引用；相同原任务原文人工式语义审查，模型审查仅为辅助。结构有效单列，不能当成内容通过。
- 预期是已确认假约束问题减少，适用边界更准确，且正常/改善案例的必要核验方法不被破坏。不能以选择数量减少或引用减少单独宣称有效。留出检查失败则不入生产，记录具体局限，不无限承诺达到100%或消除所有LLM误判。
- 如修改生产提示词先同步设计与工程文档并完成要求的独立复测。本次结果仅为固定历史输入的局部效果，不能作为重新调优原200题的独立终测结果。
