## 4. 案例仅解释现象，不代替发生率

- `71844df9`：首次分析曾把‘不强制复述’到‘避免机械复述’视作Generator加限制。后续[全量内容审查104](104-当前100题内容审查.md)复看完整限定从句后纠正：标准限定的是‘照搬且不进行反应演绎’，Chosen实际上有后续对话，Judge却称其没有反应。因此该题更直接支持Judge误判，不能截去限定从句后宣称Generator禁止一切引用。初次归因保留此更正，不计为已确认的Generator问题。
- `2fed01ed`：校对任务引用优先处理语言结构的经验，生成标准针对重复、衔接和不自然表达；该经验本次F正向，三个Checker均报correct。它是与失败例相对的观察，仍不证明无经验时做不到。
- `2c0b33a2`：询问Ancestry公司，选择了区分“信息缺失／信息错误”的经验，其应用F反向，Selector和Generator核对报error。它可用于分析适用条件与任务理解，不能仅靠Checker确定归因。
