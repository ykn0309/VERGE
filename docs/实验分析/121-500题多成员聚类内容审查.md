# 121 500题多成员聚类内容审查

2026-11-10 · 只读审查[实测120](120-General500题四路流程实测.md)最终快照中的全部多成员组。**已合并的组多数有内容依据，但这不能证明它们适合共享经验收益，更不能证明引用学习已形成可靠类别。** 没有修改算法、参数、经验正文、分组或原轨迹，也没有额外模型调用。

## 1. 范围与判断口径

最终499个任务中有11个多成员组，共26题；169条经验中有15个多成员组，共30条。其余单成员未作全量同类遗漏审查，因此本报告不评价“应合并却未合并”的比例。审查最终归属，不将最终组倒推为每题事前检索到的组。

阅读全部26组成员原文、经验三字段、实际提供边、成对分数及必要的历史结果。任务看是否共享较具体的交付形式、约束和评分需求；经验看核心核验方法和适用条件是否相近，或是否针对同类任务形成明确互补。**经验不必内容重复才能同组，同组也不等于可以合并正文或互相替代。**

下文“较强”表示同类依据较具体；“较宽”表示只支持上层归类，仍有重要边界。它们是本次Codex内容审阅意见，不是独立人工标签，不计算所谓聚类准确率。组相近和经验本身正确分开判断。

**合理的例子：180组。** 两题都要求创作同一组品牌/IP的联名广告，长题增加若干IP。它们可以共享“覆盖给定对象、自然融合、符合广告体裁”的方法；具体品牌清单仍需逐题生成。338组的两道架空历史章节也共享明确的世界内叙述、不得提真实时间线等约束，虽然具体分歧点不同。

**需要谨慎的例子：209和533组。** 209组六题共享社团角色体系与家庭/孕期背景，但结尾分别涉及临产、问候、揭晓等。533组一题是“鼓励角色分娩”的一句台词，另一题是“询问某角色去向”的一句台词。两者可同属“对话片段承接”，共同使用响应对象核验也说得通；但不能据此把紧急性、固定剧情发展或某条经验的效果一并转移。这里没有证据把它们宣布为绝对错误分组，也没有证据把它们认证为收益同质的类别。

没有发现把明显不同的事实答疑与故事创作直接合到一个多成员任务组。这26题全部是创作/叙事相关任务，多数共享角色体系、模板或大段原文；因此这些结果更能说明对相近写法和场景的识别，尚不能说明跨题材的评分需求分类已经形成。

209组中某对混合分数约0.720、低于0.75，但每个成员到其余成员的平均分仍约0.780–0.867，符合当前按平均分归组的规则。这不是程序违反门槛，而是平均规则不保证任意两成员都接近。

**相近方法确实被聚到了一起。** 例如036组都核验属性有没有绑定到正确角色，114组都核验指定词数范围，150组都核验设定中的苏醒后记忆状态。420组的原则和指南几乎逐字一致，文本相似度0.9995；后一条以前一条为parent，属于明显的去重候选，但本次未作合并或删除。

**互补经验也可以合理同组。** 600组一条要求区分前作事实与续作推测，另一条要求利用设定提出实质新构想。两条不是重复，却共同服务于“基于既有作品作假设推演”，从内容上同组合理。

**仅有宽泛主题还不够。** 315组一条检查对话是否推动情节/表现人物，另一条禁止全知旁白、心理叙述与总结；这是功能质量与叙述形式的不同要求。它们可放在“叙事表达”大类，但不能当作同一具体方法。302组的角色特异性与禁止虚构外部事实、554组的实体存在性与事实前提核验也必须保留边界。

一些同组经验本身仍过强，例如把所有奇幻创作都解释成必须吐槽、或把字数范围固定为某种容差。同组合理不等于这些内容正确，更不能通过聚类把错误指南推广成通用规则。

## 4. 这些组是不是从共同使用中学出来的？

- **经验侧：14／15组至少一条没有后续关联记录，按现行规则直接用文本相似度，关联权重实际为0。** 它们形成于语义相似，不能说成已获历史共同使用支持。
- 唯一双方都有记录的是600组：两条各仅被同一道后续任务提供过，Jaccard=1，文本0.840、混合0.880。该题为`a6a4a40882cc…`，要求设想一部既有节目的复播版本；两条单独与组合均判对，但**无经验路径技术失败**，没有完整信用。两条同来源，但这个共同任务是后续独立任务，来源排除没有违例。
- **任务侧：9／11组的所有成员具有完全相同的实际提供经验集合。** 046组一题无经验，338组一题多提供一条，除此之外均相同。这说明使用记录参与了分组，但提供集合是Selector作出的选择，不是经验适用性的独立标签；误选也可能带来高关联。
- 209组同一角色属性经验在六题中的观察信用为0、0、0、0、−1、−1。它说明同组不保证同次收益；由于任务、回答与模型波动同时存在，不能用这六次结果证明稳定子类差异或断言分组必错。

因此，当前经验组主要是文本方法集合，任务组则混合了文本接近与相同选择记录。**没有哪个经验组在本轮取得成员共同用于同一道后续任务的完整四路收益证据，不能认证“这一类经验共同使用更好”。**聚类本来也不以收益作相似度，本报告不据此判定分组无效，只明确证据边界。

## 5. 判断与后续讨论

这次逐组阅读没有发现大量明显的跨类型误合；经验组总体比任务组更容易给出具体的共同方法。任务组中有些只识别到共同故事世界和文本模板，尚不足以支持把具体经验收益视为可直接迁移。

下一步应先明确任务类别希望共享到什么程度：是“对话承接”的宽类，还是“当前事件与约束相近”的细类；不能仅看分组数量或降低门槛。对经验则保留具体适用边界，区分近重复与互补，不自动合并，也不继承同组收益。本次未采用新分类规则、未调参数，不把内容审阅当成效果验证。
