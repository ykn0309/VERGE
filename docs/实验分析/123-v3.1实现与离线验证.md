# v3.1实现与离线验证

2026-11-13。[执行计划](../plans/123-v3.1实现与离线验证.md) · [方法规范](../设计方案.md)。本次没有真实模型调用；不产生新一轮方法效果结论，也不替换logs/latest中的v3实验。

## 已实现

- 训练最多3条经验平等、分别试用，无组合。一个任务初稿R0，各路（包括无经验）均修订一次，候选复用同一初稿和既有基线。
- 每条经验独立计算相对无经验信用，未知逐条保留；全部初始路径明确判错才调用Critic。每轮最多1条候选、最多2轮，允许拒绝提案；候选技术未知不触发下一轮内容改写。
- Critic接收原始人工偏好理由、原始回答顺序映射和分值方向说明。Selector、Generator和Judge的可见内容保持隔离。候选来源验证不建边、不记收益。
- 任务组检索不设门槛，取文本相似度前3组；历史6＋全池语义4，缺额补齐。Selector训练最多3条、推理最多1条；推理不修改历史。
- 类别关联分布归一化后计算加权Jaccard，w=0.5m/(m+1)。任务低限0.35、经验0.50，在成员平均低限约束下做多起点模块度搜索，支持弱成员修复、独立成组与合并。完整矩阵不按低限删边。
- 外层最多5轮，固定矩阵内每起点最多100次扫描周期；保存每半轮的对侧划分、矩阵摘要、Q、成员最小平均、修复及预算状态，区分stable/cycle/round_cap/budget。
- 新schema为verge-v3.1；删除旧组合执行、Shapley、唯一实际训练路径、旧检查点／页面兼容，以及旧版专用验证脚本和组合测试。原始实验日志不改写，旧源码通过Git历史复现。
- Web保留原布局，改为展示共享初稿、各路修订和Judge、单候选分轮验证及原始调用；训练总览以基线正确数及逐经验配对汇总，不冒充单路推理准确率。
