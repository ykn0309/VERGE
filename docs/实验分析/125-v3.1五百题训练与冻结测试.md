# v3.1五百题训练与冻结测试

## 结果

固定v3.1代码、提示词与模型，从空池训练500题后冻结，测试200题。测试选用经验的路径复用同一任务初稿增加无经验修订对照；未选经验时复用实际路径。全部调用结束，检查点摘要未变，源码摘要核对通过，状态加载与账本／关联一致性检查通过。

| 指标 | 当前方法 | 无经验 |
|---|---:|---:|
| 全部200题判对数 | 130 | 127 |
| 技术未知 | 3 | 3 |
| 共同有效196题判对数 | 130 | 126 |

共同有效配对：14改善、10退化、116均对、56均错；另4题至少一路未知。净改善4／196，约2.04个百分点。全体正确数之差为3，是因为两路未知不是完全相同的题，不能直接当配对净收益。

155题实际选择一条经验：14改善、10退化、84均对、44均错、3未知。其余45题未选经验，共同复用路径，不能把同路结果当两次独立观测。冻结主路径130／200为65%；有效单路口径130／197约66.0%。平局算未判对，未知单列。

差异仅来自24个不一致有效配对，双侧精确McNemar p约0.541；本轮未提供稳定提升的证据，也不能由此证明没有任何作用。该比较衡量固定模型下提供经验的整体结果，包含Generator与Judge随机波动，不是单条经验文本的确定因果效果；没有直接检验纯检索等其他选择机制。

## 训练与组织

- 经验池69条。500题中110题不选、261题选1条、114题选2条、15题选3条。
- 训练账本：52改善、60退化、233均对、168均错、20未知；共享基线下多条配对不能视为独立任务准确率。训练期没有净正收益。
- 164题触发Critic，共269轮；来源通过不等于后续泛化。当前候选准入及人工理由机制并未因此认证可靠。
- 126个训练任务召回有历史分数的候选，70题实际选到其中经验。相比小样本终于覆盖了历史收益使用，但未与其他选择策略对照，不能证明历史排序有效。
- 最终90个任务组，其中62个单成员；最大两组193、135成员。69经验最终分2组（31＋38）。在线分组从1组变为多组再合并，不按组数判断质量；较大组是否掩盖不同核验需求需要后续内容分析。

## 运行与限制

训练、200题冻结主路径及附加对照总耗时约141分钟，包含初始暂停续跑和监控间隔。返回usage约输入10,778,065、输出2,444,958，共13,223,023 token；失败调用可能无完整usage，不等同完整账单。

角色合同失败事件累计Judge386、Critic121、Generator12、Selector2，包含成功纠错与耗尽，不能当作对应数量的最终失败任务。技术未知按既定规则记录，没有转为0收益；未因局部格式／网络错误全局停止。

启动检查发现旁路评估读取器需去掉JSONLogs附带sample_id字段；在12题已提交时人工中断，修正旁路脚本后续跑。核心verge源码／模型／提示词未变，未提交调用及中断保留，不重复记证据。manifest中的历史KeyboardInterrupt字段是这次已恢复中断的残留，最终运行和对照均completed。

输入为既有General去重数据第526～1025条训练、第1026～1225条测试，未用测试题更新经验或调参。该测试来自同一原始训练数据池的留出部分，不是官方独立测试集；不将此结果扩大为领域外泛化结论。已知124内容风险未在本轮中途修改。本报告是总体效果统计，不声称已完成700题内容质量审查。

## 后续
