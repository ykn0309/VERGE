## 1. 实现结果

旧规则在修订/拆分后将子版本重置为Beta(1,1)。新规则保留版本ID不可变及父退役：

```text
父总正信用P、总负信用N、已累计演化惩罚H
实际最近5例信用量W = Σ(P_i + N_i)
本次总惩罚D = 0.2W
输出k条时，每条alpha = 1 + P/k
                  beta = 1 + (N + H + D)/k
```

单条修订k=1；拆分均分，各子经验独立先验(1,1)。keep、最终同文本、失败均不惩罚。真实反馈仍按原R0权重公式累计，不撤销或折扣。已有惩罚通过继承单独带入，不参与新窗口W，也不重复计算。

InheritedCredit记录父/事件、继承P/N、继承旧惩罚和本次惩罚；不伪造子版本实际反馈。子usage、原始证据和归纳案例从空开始，父完整账本保留。Memory读取检查Beta、实际五案例窗口、父子分配、事件关联；归纳案例必须匹配已提交下游信用。

证据量改为真实及继承P+N，排除惩罚，不再等于alpha+beta−2。Selector原本就接收confidence和evidence_amount；它不计算或定义信用。此次只同步提示词中的字段说明，使之与程序口径一致，没有增加选择指标或角色职责。Web区分实际反馈、继承P/N、旧惩罚与本次惩罚，出生时间线单列继承，不显示为本版本验证次数。

Memory8、Manifest/Trajectory10；Prompt标识immutable-atomic-evolution-inherited-credit-v2。旧协议拒绝读取/resume，不增加迁移兼容，旧产物未改。
