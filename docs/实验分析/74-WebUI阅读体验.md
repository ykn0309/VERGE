# 74 — WebUI阅读体验优化

仅调整静态前端及其交互回归，不改LLM角色、提示词、实验流程、统计规则或实验产物。现有Web服务无需重启，刷新即加载新资源。

## 展示变化

- 顶栏保留运行概览、样本流水线、经验池，不新增全局左侧导航。概览直接展示首次/纠错后结果、引用与Checker覆盖、反馈分布、待复核样本。
- 列表使用样本#01与经验E01短编号、中文状态、搜索/筛选；支持#12、E02搜索、活跃/退役切换及按Q/下游引用排序。详情与列表分开滚动，普通点击保持列表位置；从来源或深链接跳转时定位目标。
- 样本详情分成任务与回答、评分标准、经验与核对、Critic纠错、调用记录。回答并排，保留段落、列表、粗体、代码及简单表格，长内容可展开；原文中的HTML只显示文字，不执行。
- 逐条标准直接显示整体归一化权重、经验来源、两侧满足/未满足及可展开的Judge依据。原始题目/判断不改写。
- Checker按实际引用经验分组，以三个意见卡显示适用性、应用、Judge执行核对；区分报告错误与人工真值，保留逐标准细项、F、综合O、未更新Q原因。未引用和准入不检查的情况直接说明。
- Critic按真实轮次展示分析、各候选的Trigger/Principle、反馈及最终入池结果；保留本轮标准与失败原因。仅有Updater事件、没有Critic轮次时也能查看修订。
- 经验分方法、应用与核对、版本演化；来源/下游/回放各自统计和筛选。长ID、参数来源和原始JSON放在元数据或调试展开中。
- 调用记录按需加载和缓存，可按角色筛选、阅读原始回复/完整消息/编号映射；刷新清理旧缓存。搜索保持输入焦点并同步匹配详情，连续切换运行时丢弃过期请求。
