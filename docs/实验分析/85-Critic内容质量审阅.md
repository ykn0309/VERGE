# 85 — Critic内容质量审阅

此前将结构检查概括为“复测通过”不准确。本次补查计划84的全部20条Critic输出，分别核对诊断依据、候选方法合理性、原子性、通用性及任务外要求。没有追加模型调用，也没有修改生产提示词或原实验产物。

这是本助手的逐题内容判断，不是独立人工真值。样本由15个首次失败任务及5个成功边界任务组成，偏重问题案例，不能估计整体候选合格率；涉及外部专业事实的判断未另行查证，不作为已确认事实。

## 代表性证据

- critic-12：Critic称两回答约350/360词，实际上按空白计数为538/489词，按英文词正则计数为531/488词，均落在原标准450–550词范围内。其字数不足诊断不成立，候选还转成要求回答自报合规，偏离评分标准设计。
- critic-15：把“In character”解释为必须第一人称，进一步禁止第三人称代词。即使要求第一人称，也仍可使用he/she/they指代其他人物，这项限制过强。
- critic-20：把背景台词和标题变成必须原样复述的要求，原任务没有这一要求；同时未识别Judge关于原文引用的依据不实。
- critic-18：识别到回答将水描述为遇火产生火花，提出核验现实对象属性、避免词义混淆的通用方法。此候选可保留，不代表已证明跨任务有效。

## 后续复测口径

各模块均应同时报告结构结果与内容结果。Critic检查诊断是否读对轨迹、候选是否有任务依据、是否原子且可复用；Generator检查任务要求与经验是否落实且无额外约束；Selector检查适用性而非仅主题相关；Checker检查结论和理由是否得到输入支持；Updater检查修订是否解决问题并保留必要方法。没有完成相应内容审阅时，明确写“仅完成结构检查”。
