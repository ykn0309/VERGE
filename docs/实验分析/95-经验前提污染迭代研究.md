# 95 — 经验前提污染迭代研究

状态：多机制开发验证未达采用门槛，尚无可采用生产方案。分支codex/experience-premise-research；承接报告94。正式概率参数估计仍暂停。

## 为什么继续

报告94的单提示改动没有阻止经验污染任务分析。本次在独立分支测试不同机制，不以“理由更长”“引用更少”作为成功。现有工作树修改被保留，生产提示和冻结经验池不变。

## 已执行的转折

- 第一轮：原版、任务无关编译、任务先行槽位。普通编译仍保留原禁令；槽位因空目标及精确引文校验导致13/30失败。未采用。
- 第二轮：加强反例式编译，移除引文硬门槛，未知目标显式降级。120份结构有效，但前提与禁令仍在，不能把降级无经验当效果。
- 第三／四轮：另一个会话只看task和草案标准，不看经验与原analysis。部分目标误用解除，但出现范围缩减、数字限制、评价输入等新增问题。未采用。
- 第五轮：只允许经验传递任务要求ID，阻断文本传入最终作者。减少了部分污染，却损失方法细节，且14/60被过严绑定校验拒绝。不能声称完全解决。
- 第六轮：组合旧Terra规范化副本、无经验任务要求、槽位生成、不看经验的独立修订；30题各两次，59/60结构有效。典型误用改善，仍有新增细节错误。
- 第七轮及同协议重复：仅最终Flash修订开启思考，仍见新增约束、背景复述等问题，不声称思考优胜。
- 第八轮：固定第六轮中间草案，只换最终修订器为服务模型列表中确认的Qwen3.5-Plus-2026-04-20，关闭思考。一次分派错误运行实际仍为Flash，发现后停止，完整留档为INVALID；正确运行另存round8-corrected，不混入结论。正确运行58/60结构有效，年份题的一条标准被2条下限拒绝。
- 第九轮：只在研究原型允许最终1至8条标准，从同一草案重跑60份；出现一份将格式说明直接作为question的输出，结构成功不等于内容成功。
- 第十轮：加入明确示意占位文本的拒绝与具体错误反馈，重跑60份；目标误用明显改善，但仍预断未发生事件，未采用。
- 第十一轮：固定草案和提示，仅最终Plus修订开启思考，60份结构有效；仍会预断后续事件，未采用。
- 第十二／十三轮：逐条构造反例，分别接复杂链和原版草案。60/60及59/60结构有效，但保留错误禁令、漏掉体裁等核心要求，未采用。
- 第十四轮：固定反例的确定性重放，保护task中出现的字面数字，60/60结构有效；仍有all变主要、100字符变最多100等语义损伤。没有新增LLM任务。
- 第十五轮：原经验＋Plus思考直接生成，与同Plus无经验对照，各30题两次，120/120结构有效。前提与格式策略仍在，模型升级不等于解决。
- 第十六轮：Plus思考只看32种原经验，编辑一次后交原Flash生成，60/60结构有效；仍把NEFA视作存疑、把3变体变成3份不同描述，未采用。
- 第十七轮：Plus不思考先筛选原经验，再交原Flash；配同Flash无经验对照，120/120结构有效。过滤器会用“部分方法有用”为整条强策略开脱，仍有错误先声明及格式要求。
- 第十八轮：Plus思考先核实前提并构造违反整条经验的合理回答反例，再由程序过滤，原Flash生成。已发现严重误删：将剧情引用错误的文章说成合理反例，不能把拒选增多当成成功。完整数量与案例见下节。

所有轮次均为独立Generator研究原型，不调用主流程训练或Judge，不更新Q，不将开发结论当总体准确率。JSON传输复用backend的角色标签，日志中的critic不代表运行了生产Critic。

## 证据范围

开发固定30个不同历史任务，18原退化、6原改善、6原双方正确。重复不是新任务。关注前提臆断、额外义务、核心覆盖、合理方法保留和普通任务损伤；含糊对话、数量范围、未经核实的外部事实保留不确定。多步组合的贡献不能归给单独一句提示。

旧规范化副本是实质内容干预，不是自动编译器已达标；没有继承旧Q。新20题输入已按固定种子预选，与开发30及旧确认25无交集，尚未运行确认。来源仍是历史配对实验，不是新的自然分布留出集。开发通过后才冻结候选确认，不选择单题最优输出拼成成绩。

产物：artifacts/premise-research-95，包含各轮代码副本、实际消息、返回、错误、用量、协议、方法来源与无效运行说明。原实验与池继续受摘要保护。

## 内容证据与决策

目前没有方案同时满足“减少经验污染、保留核心要求、保留合理方法、正常案例不新增严重问题”。因此未启动预选20题确认，未改生产Generator或原经验池。不是因为确认失败后放弃，而是开发尚未达到冻结门槛；旧的潜在候选冻结文件已归档并标记开发否决。

| 任务／要求 | 发现 | 对判断的影响 |
|---|---|---|
| low nefa | 复杂隔离修订能改为解释术语；自动经验编辑后Flash仍强制指出拼写或未证实 | 单改经验措辞不充分，知识／应用能力仍影响前提判断 |
| 角色react，未规定标签 | Plus直接生成、普通过滤都继续强制Name:与动作标签 | 更强模型或多写理由不能保证方法不变成义务 |
| 解释圣经章节 | 原方法禁止所有建议；部分修订解除，原草案反例臂仍保留禁令 | 审查器也可能认同错误策略 |
| SEO作品描述含3变体 | 复杂隔离与部分过滤正确记作品属性；自动经验编辑仍出现必须生成3份不同描述 | 需要区分属性说明与新增交付；已选经验固定不代表适用 |
| 1080x1080、3变体 | 反例审查会改成同形规格或合理数量；字面数字保护能阻止该次删除 | 数值保护只能防一类改写，不证明旧标准正确 |
| all characters | 第十四轮两次仍缩为主要／相关角色 | 修好额外义务时可能损失原有覆盖，不达标 |
| 标题only100characters | 第十四／十六／十七轮仍写最多100，十五轮一次精确一次最多 | 精确与上限混淆是跨臂普通任务错误，非全由经验造成 |
| 对海洋讨论发短回复 | 第十四轮回到讨论回复，不要求吸气；Plus直接应用仍写延续动作标记 | 局部机制有效，但不能外推为整体安全 |
| 第四天诗歌续写 | 部分修订仍预定第四次失败，或强制固定情绪；合理走向可为成功交诗 | 背景模式不能当未发生事件的事实 |
| 班柯分析的原文依据方法 | 第十八轮把虚构篡改剧情的文章说成合理反例，从而拒绝事实核验 | 反例必须本身正确；审查模型输出不是有效性真值 |

这些是根代理逐题阅读任务、方法与实际标准后的定性记录，没有将模型报告直接计为真值；医疗、冷门人物和节目等事实并未另做外部核查，不在这里断言具体世界知识准确率。含糊且无明确指令的已完结故事，目标解释保留争议，不强行算通过。

## 方法与实现边界

研究实现集中在`scripts/research_premise95.py`，每轮保存代码副本、协议、真实输入输出、错误、用量与中间结果。测试覆盖固定草案实际模型分派、思考开关、新输入不会读取开发草案、任务无关编辑、过滤前后经验ID、数值保护和示意占位拒绝。研究允许最终1—8条标准，不改生产2—8条契约。

发现过一个真实实验错误：round8本应调用Plus，却进入Flash组合分支；中止后保存INVALID，正确运行另存。它的30份结果完全排除效果判断。guarded_full另一个潜在分派错误在运行前发现并修复，增加三臂回归检查；该臂没有真实模型效果结果，不声称确认成功。第十四轮是确定性处理已有审查，不算新模型案例。

第十五至十八轮分别改变模型、任务无关经验编辑、前置过滤、具体反例过滤。它们不是同一变量的四次统计重复；复杂组合也无法单独归因于某一句提示。旧Terra规范化副本是实质内容修订，不能当自动编译器已可靠。未沿用原Q评价这些改写方法。

## 当前判断与下一步边界

本轮已经排除了几种过于乐观的解释：不是多提醒一句就够，不是改成温和条件句就够，不是更强模型必然会正确应用，也不是增加反例审查就不会误删。直接再叠一层同类LLM审查，尚无证据能突破这个问题。

因此保留所有原型与反例，不采用生产替换。下一次机制实验应先明确“有用核验关系”和“错误回答策略”如何分开表示及验证，再测试是否既能保留前者又抑制后者；不能把大部分经验过滤为空后宣称经验迁移成功。正式概率参数估计、整体训练／测试仍未恢复。本报告只给Generator模块的局部开发结论，不给新的回答偏好准确率，也不宣称已解决根因。
