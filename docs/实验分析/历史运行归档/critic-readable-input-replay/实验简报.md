# Critic可读输入、Judge理由及标签复测

生产Critic已改为逐标准分块：问题/权重/来源先展示，两侧判定和Judge解释分别换行。保留原始中文偏好标签、满足/未满足及完整理由，理由标为待核对；真实多轮历史、完整task/回答、短编号、输出协议和经验机制保持。这里完成的是消息展示改进，不能声称已修复语义误读。

## 范围与验收

固定历史trace 163、167、724、4、390、281，共6条输入、5个独立任务；167为真实第二轮，首轮assistant原文保留。Qwen3.5-Flash、关闭思考，36份输出均结构有效，37次实际请求：首题words_separate发生一次ReadTimeout后以相同消息恢复，无格式/结构纠错。全套301项测试通过。源manifest、role_io、Memory和trajectories哈希未变；没有运行流水线或写经验池。

六版本：中文标签+理由紧随各侧判定（words_inline）、中文+解释独立区（words_separate）、中文+不提供解释（words_absent），以及A/B+中文判定、中文偏好标签+true/false、A/B+true/false。后四者构成2×2标签对照，共用相同理由布局。所有版本均加相同的映射说明；生产没有新增这段实验说明，因此不能将复测默认组直接视为生产效果。实际payload不变，删除理由只改变模型可见消息；原文没有全局替换或截断。

A/B在感受题和部分故事判断上局部改善，true/false本身没有一致优势；组合版也出现视频漏诊和世界内外范围混淆。没有稳定跨案例优胜者，因此生产不采用标签替换。模型并非完全不理解“优选/非优选、满足/未满足”：多版本能准确读出判定方向，但仍会越过事实创造规则。

## 仍存在的问题及边界

1. 偏好差异仍容易被当作必须生成新规则的理由，甚至公开trigger依赖已经观察到的回答或分差。
2. 能读对Boolean，不等于能核对事实；删除理由后仍会误引另一回答，第二轮真实旧分析中的错误也没有被稳定纠正。
3. 能发现Judge误判，不等于提炼出符合现有协议的经验：有版本提出前置否决、固定阈值或强制格式。
4. 香蕉故事并非“所有约束完全正确”的金标准：task要求ground而优选在attic；标准把“主导物种”扩大成“明确排除人类”，非优选也未显式描写完整发现过程。空候选只表示没有新造这些已知假规则，不能记为全面正确。帐篷两文均覆盖核心请求，非优选长篇重复背景可以作为叙述效率线索，但task未规定不得复述，不能以空候选/非空候选单独打分。

每个输入/版本仅一次生成，第二轮来自同一任务，不按6个独立任务统计；不同版本会改变可见信息和展示，这些是局部行为证据，不是内部机制证明、整体准确率或经验因果收益。若继续优化，优先针对“偏好信息不是任务约束”“发现误判不等于必须造经验”设计少量严格原创对照例，再独立复测；本轮没有追加该实验。
