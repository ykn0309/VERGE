# 共同方法优先提示词：27次历史拆分输入复测

2026-10-13。用户确认只改归纳提示词、不增加analysis，并授权有限复测。结论：有局部改善，但仍频繁拆分近似方法，也出现过度合并丢失必要方法，不能认为问题已解决。

## 范围与核验

- 来源：`helpsteer3-general-split-experience-qwen-flash-100-resume3`，只读取27次原本发生拆分的实际输入；逐条匹配原始role_io和父案例顺序，不重建或截断回答。
- 模型：Qwen3.5-Flash、enable_thinking:false；沿用原30秒超时、2次API/格式重试和2次结构纠错。不调用Generator/Judge/Selector，不更新原经验池、案例和信用。
- 每组独立固定输入，只替换ExperienceUpdater提示词。原案例中已有的经验文本和Judge错误仍在输入；新输出不会反馈到后面的组，所以不是新训练轨迹，也不估计下游准确率。
- 280项离线测试通过。26份有效输出结构、唯一完整案例分配、无analysis字段及40份实际请求消息已核验；源数据/Memory/轨迹/role_io/原manifest/审查文件哈希不变。接受文本content最多80字符、trigger最多31字符，仅观察，不做长度验收。
- 第15组因sample_id漏字符/删除前缀，3次结构校验均失败，记为无效；没有追加业务重试。脚本起初在该错误处退出，随后补齐与生产一致的格式/结构失败记录并继续规则，从现有3份原始回复恢复无效记录，未重复调用该组或前14组。

## 下一步判断

这版提示词可作为已实现的改善尝试，尚不足以直接扩跑证明效果。主要残留是归纳员仍受当前经验和错误标准锚定，以及“优先一条”可能让模型删除必要核验动作。若继续优化，优先讨论是否用程序显式提供保留/拆分两个候选结构供比较，或改善案例进入归纳时的方法归属证据；本轮未实施新机制，也不新增analysis、自动案例过滤或模型调用。

本轮结束，不启动剩余训练、held-out、新一轮提示词搜索或提交/push。原Web保持沙盒外进程不重启，继续显示原100条结果；本复测是独立报告，不伪造训练manifest进入Web。
