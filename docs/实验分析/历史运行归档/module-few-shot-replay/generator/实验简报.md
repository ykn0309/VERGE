# Generator few-shot 独立复测

结论：**当前3个合成示例没有带来稳定改善，不建议直接加入生产提示词。**England案例删除了无依据的19世纪，但来源落实、人物覆盖和不确定性判断仍有问题；同时出现比较目标和可操作性弱化。

## 范围

从100条历史运行选4个真实Generator请求（3个有明确问题，1个正常对照），当前提示词baseline和追加few-shot各调用一次，共8次Qwen3.5-Flash、关闭思考。全部合法、无格式/结构纠错，源文件hash检查未变。只调用Generator，不运行Judge或整个流水线，不回写经验池。

few-shot是独立编写的3个虚构设备比较、维护说明改写、操作记录交接示例，不从数据集提取或改写。实际历史非system消息逐字保留，只替换system为当前版本或当前版本加示例。结果见[results](results/)，逐项检查见[review.json](review.json)。

## 后续建议

先不部署这组Generator few-shot。若继续本模块，应针对“不要把经验中的条件前提当已知事实”和“材料中的示范格式不等于完整操作指令”分别优化独立示例，并检查是否保留比较/提取目标；不是继续堆同类来源说明。必要时先确认输入歧义处理原则。

本次只说明4个固定历史输入的局部行为。每组一次、有选例偏向，不证明整体效果、随机性稳定性或因果收益。
