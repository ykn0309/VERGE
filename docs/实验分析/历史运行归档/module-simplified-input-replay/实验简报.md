## 定向few-shot准备

Generator另存两个原创候选示例，聚焦“条件性经验不提供当前事实”：缺规格不等于实体不存在；差异处理经验不意味着两份记录一定有差异。Selector/Judge另存修正后的旧候选示例，解决故障编号/名称不一致及计数括注矛盾。保存为各目录few_shot-proposal.json，输出契约已检查，均未混入本次调用或加入生产提示词，历史示例和日志不重写。

下一步可独立检验Generator定向示例，但不因本报告自动追加调用。没有更换Critic提示词、增加字段或验收调用，也没有训练、held-out、信用更新、Web重启、提交/push。输入精简为已实现的工程调整，语义收益仍待验证。
