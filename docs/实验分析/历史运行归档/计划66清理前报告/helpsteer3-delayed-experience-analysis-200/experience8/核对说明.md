# 经验8：高使用频率、约50%置信度的原因

对象：最终池第8条，`exp_094583091100442786f2d699273c5ac0`。只读核对当前200题来源；`all_uses.json` 保存58次下游信用任务的完整任务、两回答、69项R0引用标准、权重份额及Judge依据。逐项查看69项问题及结果，并重点阅读第63、89、93、105、148、161、191、198题的完整回答；原题57及既往审计卡片作为补充。没有外部事实核验或新模型调用。

## 信用重建

下游58个任务中14个净正、44个净负；69项引用标准有14项正确区分、3项反向、33项两回答都满足、19项两回答都不满足。标准数、信用事件数和任务数不可混用。

| 来源 | 正信用P | 负信用N |
|---|---:|---:|
| 原题57候选验证 | 0.400 | 0.150 |
| 下游正确区分14项 | 3.450 | 0 |
| 下游反向3项 | 0 | 0.475 |
| 下游同判52项 | 0 | 3.25625 |
| 合计 | 3.850 | 3.88125 |

先验alpha=beta=1，最终 `(1+3.85)/(2+3.85+3.88125)=49.8394%`，入池54.902%。下游同判负信用中，两回答都满足占2.025，两回答都不满足占1.23125。负信用主要不是“rejected满足而chosen不满足”，而是没有区分出两回答。

这是当前已确认规则的直接结果：引用多不会自动升分；需要加权正信用超过加权负信用。多次应用让证据更充分，但若多数是同判，分数不会高。

## 合理核心确实有用

原题57是“we need space”，当时其他经验引出了无关的感官细节与角色能力标准。新经验要求信息缺失时允许澄清、假设或通用解释，避免强制依赖缺失情境的细节。这个方向合理；原题Judge把rejected的“Could you please be more specific?”在澄清标准下判false，理由与标准也存在不一致，因此原题正信用不能视为全部可靠。

105题：用户说自己在做恐怖游戏，想介绍主角。chosen请用户分享；rejected擅自创造姓名、年龄、职业、创伤和外貌。经验8产生的“不擅自编造角色”标准正确区分，P+=0.6，原文支持清楚。

## 同判不等于内容错误

63题问世界人口，两回答都注明年份、都用estimated/around/approximately表达估算性。两项引用标准都判true/true，N+=0.15。这里仅说明这些要求不能区分这一对回答，不说明“标明时间和不确定性”本身错误；本核对不判断人口数字的外部真实性。

93题两回答都说明评价具有主观性，true/true导致N+=0.075。148题的引用标准检查优缺点的逻辑解释，两回答都满足，N+=0.05；这条标准与经验8的具体方法联系较弱，还存在引用范围泛化。

## 从不强制编造，变成限制创作

原始方法是“缺信息时不应强制要求生成虚构细节”，归纳后变为“无具体场景时优先通用解释或假设声明，避免编造虚构细节；若需创作基于合理框架”。第64题更新一度直接写“避免编造具体感官细节、角色行为或特定情境”。不强制某种细节，与禁止回答添加这类细节，不是同一个要求。

161题明确要求创造理论语言，chosen标题写“A Theoretical Construct”。经验8的标准与Judge仍把具体音素、后缀和语序当成不应编造的细节，两回答都false，N+=0.1。允许构造虚拟语言，与禁止把其说成现实存在，需要区分；不据此认定chosen的语言设计其他方面均正确。

198题明确要求跨品牌广告，chosen开头写“could look like this”，结尾用would。该引用标准下Judge却说未提供假设前提，并将剧情中的玩具、游戏币和VIP旅程当作违规虚构，两回答都false，N+=0.05。原文已有假设语气，判定理由遗漏了它；标准也没有清楚区分创作细节与事实断言。

191题Judge扣分还涉及所创作场景的合理性，89/185题涉及外部游戏/气候事实，不能不核验就把所有负反馈一概称为错判。本说明确认存在合理同判扣分及创作边界误用，不估算58次应用中全部误判的占比。

## 冻结使后续问题不能再修正文案

经验8在第60、64、84题完成三次归纳，第84题达到10案例，置信度48.78%。之后49次下游应用仍计信用，却不收案例或归纳，因此161、198题出现的边界问题没有进入该经验后续文本更新。

结论：经验8有正确且可复用的核心，但当前文字及应用存在边界泛化。49.8%主要由大量同判轻负累积造成，不能直接读作“这个原则大约只有一半正确”。保留当前计分规则的前提下，优先澄清的是：只有需要事实依据或忠实承接既有材料时，才禁止无依据事实断言；用户授权创作时允许合理补充。这里提出诊断方向，不改经验池、公式或生产提示词。
