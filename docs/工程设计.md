# VERGE 工程设计

> 当前以[计划65](plans/65-原子经验类别检索与同判独立记录.md)为准，方法见[总览](设计方案.md)。Manifest/Trajectory8、Memory6；历史产物保留，拒绝跨协议resume。

## 1. 结构与预算

verge源码保持扁平，不新增服务或数据库。训练单进程顺序执行，测试冻结Memory后有界并发、按顺序提交。角色为Selector、Generator、Judge、Critic、ExperienceUpdater、CategoryOrganizer；不再有Admission/Fusion模型。

Critic每轮一次0–1条提案，最多两轮；每次应用为全新Generator。格式结构纠错单独有限计数，不增加业务机会。Generator固定E快照，每轮只替换C；Critic保留样本局部真实消息，第二轮追加应用反馈。

## 2. 资格、记账与收尾

R0有效Judge后、成败分支前按已有E来源累计P/N，反向按完整额度计N，同判仅记录双方满足/双方不满足标准次数，不记P/N，无折扣、不先抵消，alpha+=P、beta+=N。R1/R2 E不重复记账。

候选采用且自身P>N为eligible，使用输入十进制权重的精确比例判断，不凭浮点净值或整体margin。合格先暂存；整体失败可继续第二轮，正常结束只选最新合格候选（C2优先，否则C1）。新候选直接保存原文，新ID、Beta(1,1)追加对应轮次P/N，未选候选留轨迹，不合并信用。

整体任务状态与入池记录独立，整体失败可入池，整体成功可无入池。空候选、无效轮耗尽可正常回退C1；Judge错误、角色拒答或请求重试耗尽的错误结束不入池，有效R0信用保留并完成有限案例收尾及轨迹保存，再进入下一样本。请求隔离边界见[计划63](plans/63-请求失败样本隔离与经验排序.md)；鉴权、配置、存储及程序错误仍fail-fast。

## 3. 经验文本归纳

训练R0有实际信用的已有经验，在候选过程结束后收录不同sample_id的有区分数值证据的正负案例，同判不归纳，包含原题最多10条。原题不计窗口，每3个不同下游任务归纳；成功（包括合法保持文本）重置窗口，失败不重置但同一新案例只尝试一次，第10个案例强制最后尝试，随后文本/案例冻结，继续信用。

输入discriminating_cases_v4：当前content/trigger及全部有限案例，完整task/两回答，只保留引用本经验的标准问题、Judge Boolean/reason及feedback=positive/negative；混合案例只投影有区分的相关标准，不让同判进入归纳。不传P/N、权重、共享来源数、无关标准、整体分数或私有分析。实际使用文本不同才附applied_experience。不截断回答，不做额外摘要或审核。

Generator的已选经验输入仅保留experience_id/content/trigger，不提供confidence/evidence_amount；当前候选仍明确标注尚未验证。Selector保留可靠性信息用于筛选，Critic保留诊断所需权重、来源、逐项结果/理由及真实多轮历史，Judge仍只接收task/标准/单回答。领域对象、经验信用、轨迹和选中快照继续保留完整数值。

归纳案例标识见[计划51](plans/51-归纳案例短编号.md)：真实模型只见本次短数字案例编号，输出仅content/trigger，不抄案例ID或分组；实际消息预算按投影计算，存储保留真实ID。

所有角色的程序对象标识均经NumberedIDCodec映射为本次局部数字编号：Selector/Generator的经验与候选、Judge的标准、Critic的标准集/标准/来源/前轮候选，以及归纳员的案例。Critic继承已投影的真实消息历史，每条新增反馈使用本条局部编号；输出在领域校验与保存前还原真实ID。Embedding只接收task、未分类小经验正文/trigger或类别名称/描述及全部成员正文/trigger，不带对象ID；不为隐藏程序标识改写任务和回答原文。

归纳员只修正当前一种原子方法，返回非空content/trigger；150/60字符仅提示词，不校验长度。保持ID/Beta，文本变化才version+1，保存前后文本、版本、案例IDs及error；取消拆分、父子关系及继承信用分配。历史信用不自动认证新文本，当前样本固定E不变。

完整system/user UTF-8文本预算100,000字节，不静默截断。预算超限、格式/结构耗尽、归纳拒答或归纳请求重试耗尽保留旧文本、合法信用与已收录案例并记错误，不改变样本判断状态；鉴权、配置、存储、Calculator和程序错误fail-fast。预算控制不保证任意提供商上下文一定可用。

## 5. 冻结、Web与验收

held-out冻结内容、案例和Beta，只检索/选择/R0/Judge，不生成候选/归纳/记账。stop_after_train限制绝对已处理前缀，暂停不启动测试。真实角色固定Flash非思考，新实验使用独立目录。

Web仅loopback只读，仅列新Prompt/Manifest运行。展示整体Judge状态、候选eligible和最终入池、经验案例数/版本/冻结、正负信用、下游任务数、待归纳反馈及文本演化错误；不把历史信用当作新文本验证。历史旧协议产物保留，由原运行服务继续只读查看；新源码仅处理新协议。本轮不启动或重启Web。

测试覆盖局部资格/精确平局、延迟C2/C1选择、错误边界、P/N与版本、10/11条、样本去重/固定E、输入预算、向量失效、冻结、resume、真实HTTP消息及Node前端转义。离线通过不证明语义泛化改善，效果需后续新实验。

## 6. 类别组织与检索预算

新小经验入池或content/trigger变化后入队，按ID去重并记录最新版本；信用变化不入队。modules.application.config.organization_batch_size默认5，样本收尾达到阈值整理；训练停止/暂停时处理剩余。收尾事件在Memory分类历史归属于最后已完成训练样本，请求日志同样带该sample_id。失败保留原归属与队列，同一待整理版本不反复调用，有新的入池或正文变化后再试。

分类只输入全部小经验的正文/trigger/当前归属、现有类别名称/描述和待整理编号。用同一次模型调用输出完整分类方案，成员恰好归属一次；程序先校验全部方案再保存，不能改变小经验正文、信用或案例。类别编号与经验编号使用不同的短ID命名空间，新类别用null由程序分配ID。保持现有类别身份时沿用ID，允许更名、修改描述、迁移成员、留未分类或删除空类别。格式结构有限纠错；完整输入预算100000 UTF-8字节，超限不截断。

向量召回20个类别/未分类经验单位，类别命中完整展开；Selector按类别看到成员，输出仅小经验ID。完整Selector输入默认100000 UTF-8字节，modules.selection.config.input_bytes可配置；超预算记录样本错误，不截断类别/经验，不额外调用分层筛选。类别或成员文本变化使类别向量失效，信用变化不重编码。Generator不接收类别信息，区分率不接入Selector。

Web在经验页展示所属类别名称/描述、类别筛选、正确/反向/双方满足/双方未满足标准次数及仅展示的区分率，保持独立置信度和引用排序。旧协议产物保留，新源码拒绝旧schema，不迁移或跨协议resume。
