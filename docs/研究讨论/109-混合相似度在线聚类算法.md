# 文本与引用混合的在线聚类

2026-11-07。**算法候选，尚未实现或验证真实效果；参数为暂定初值。**

核心：任务和经验分别分组，每个对象只属于一个组。与已有组足够相近就加入，否则新建；引用变化后允许换组。选择经验时，可以参考多个相近任务组。

## 1. 保存什么

- 文本向量：固定嵌入模型生成，任务使用原文，经验使用“适用范围＋核心方法＋生成指南”，不含回答、标签或收益。
- 具体引用集合：任务引用了哪些经验；经验被哪些任务引用。以Rubric实际引用为准，检索或提供过但未引用的不计。
- 所属组：保存组ID，组关系由个体记录汇总。

同一任务可引用多条经验；跨尝试取引用并集，重复引用不增加次数。原始轨迹分别保存，来源验证不算独立下游收益。

## 2. 两个对象怎样比较

只比较同类型：任务对任务，经验对经验。

**文本相似度T：**单位向量的余弦相似度，裁剪到[0,1]。

**引用相似度J：**引用集合的交集大小／并集大小（Jaccard）。

混合规则：

```text
m = 两个引用集合大小的较小值
w = λ_max × m / (m + 1)
S = (1−w) × T + w × J
```

任一引用集合为空，直接使用T。引用越少，权重越低；文本始终参与。这个权重是简单的设计建议，不是已校准概率。

## 3. 怎样加入或新建组

对象与组的得分：**它与组内其他成员的S取平均，排除自身。**

新对象找到得分最高的组：达到门槛τ就加入，否则独立新建。得分相同时按稳定组ID选择。任务和经验各用自己的门槛，不预设组数。

## 4. 引用变化后怎样换组

先保存本轮完整引用，再按固定ID顺序检查。记当前组得分为a，最佳其他组得分为b：

- b达到门槛且大于a：换到该组。
- 当前组还有其他成员、a低于门槛，其他组也不达标：独立新建组。
- 其他情况不动；平分不换组。单成员当前组的留组分数按τ计算。

每次在线更新可检查多轮，每轮按固定ID检查所有对象（含刚入组对象）一次；一整轮没有换组就停止，否则继续，直到最大迭代轮数R_max。每次移动立即更新成员信息、删除空组；后续判断读取最新分组。组变化也会影响其他成员，不能只检查引用边的端点。引用集合与文本向量在本次多轮检查中固定。达到上限但仍有移动时，标记“未稳定”，不冒称收敛。

训练时先用已有状态选经验，任务完成后才更新引用和归属。推理时冻结历史分组。该过程可能受输入顺序影响，不保证全局最优。

## 5. 选择经验时怎样用组

新任务到每个任务组的得分，同样取成员相似度平均；没有引用时只用文本。

可先取最多3个得分达标的组，汇总历史效果、去重排序，再交给LLM筛选经验。没有达标组时，回退直接检索相近历史记录或不用经验，具体回退规则另定。

**类别关系只提供优先级，不限定经验候选范围。**训练利用已有收益时优先参考相关组；探索时从全经验池按语义检索，允许尝试未与当前任务类建立联系的经验，而不是只在已关联组内选低证据经验。实际引用后再更新联系，探索比例仍待定。

**查询多个组不改变单一归属。**同一经验和历史轨迹不能重复计算；聚类不负责拆分多经验组合的收益，也不自动合并经验正文。

## 6. 伪代码

输入：历史对象、引用集合N、当前分组、完成的轨迹r，以及λ_max、两类门槛τ和最大迭代轮数R_max（正整数）。输出：更新后的引用与分组。

```text
相似度(x, y):                           # 只比较同类型对象
    T = clip(dot(x.单位向量, y.单位向量), 0, 1)
    if N(x)为空 or N(y)为空: return T
    J = |N(x)∩N(y)| / |N(x)∪N(y)|
    m = min(|N(x)|, |N(y)|)
    w = λ_max × m / (m+1)
    return (1-w)×T + w×J

组得分(x, C):
    M = C的成员去掉x
    if M为空: return τ(x.类型)          # 当前单成员组的留组分数
    return mean(相似度(x, y) for y in M)

在线更新(r):
    保存r；补齐新对象的固定文本向量
    按实际引用更新双向集合N，重复边只保留一次
    刷新引用变化所影响的相似度缓存

    for 新对象x，按稳定ID顺序:
        C = 同类型非空组中，组得分最高的组
        if C存在 and 组得分(x,C) >= τ(x.类型): 加入C
        else: 为x新建单成员组

    for round = 1 ... R_max:
        changed = false
        for 所有对象x，按稳定ID顺序:
            C = x的当前组；a = 组得分(x,C)
            D = 除C外，同类型非空组中得分最高的组
            if D存在 and 组得分(x,D) >= τ(x.类型) and 组得分(x,D) > a:
                将x移入D
            else if |C| > 1 and a < τ(x.类型):
                将x移入新建的单成员组
            else: continue
            changed = true
            更新成员信息，删除空组
        if not changed: break
    根据最终归属重汇总组间关系和相关效果记录
    返回分组、实际轮数、是否稳定 = not changed

检索任务组(q):                         # 利用阶段的检索，不是探索候选的硬边界
    计算q到每个任务组的组得分
    返回得分达到τ_task的前3个组          # 不足3个就返回实际数量
```

没有候选组时返回空；加入／检索遇到同分按稳定组ID排序，已有对象同分不换组。组得分读取最新成员，移动引起的再次调整可以在同次更新的下一轮处理；训练任务完成后才调用在线更新。

## 7. 暂定参数与待验证项

| 参数 | 初值 |
|---|---|
| 引用最大权重λ_max | 0.3 |
| 任务门槛τ_task | 0.75 |
| 经验门槛τ_exp | 0.75 |
| 最大迭代轮数R_max | 5（用户确认的暂定默认值） |

R_max=5用于限制更新成本；整轮无换组提前停止，记录实际轮数与是否稳定。若经常跑满仍未稳定，再比较10轮的收益与成本。

先与λ_max=0的纯文本对照比较，检查组数、单成员比例、换组频率、顺序敏感性，以及是否帮助后续经验选择。引用不同可能把语义相近的对象过度分开，平均相似度也不保证组内任意两者都相近。
