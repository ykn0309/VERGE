# VERGE — 设计总览

VERGE（Verified Experience-guided Rubric GEneration）研究：

> 如何从 preference trajectory 中提炼 rubric-generation experience，并根据修订贡献与未来任务中的实际表现动态维护经验可信度，从而改善后续 rubric generation？

本文件只描述总体结构。每个模块的规则、公式和边界由对应子文档负责。

---

## 1. 总体流程

```text
Experience Memory
→ 向量广召回
→ LLM 经验筛选
→ Initial Rubric Generation
→ Rubric Judge
→ 已有经验信用分配
→ Reliability Update

如果 Initial Rubric 失败：
→ 最多两次、均从 R0 出发的 Atomic-operation Revision
→ Revision Executor 应用 operations 生成 revised rubric
→ Revision Success 后 Reflection 生成候选经验
→ Revision Credit Assignment
    ├── 计算 operation 收益
    ├── 绑定 candidate 与 operations
    └── 分配 candidate credit
→ Admission
→ Experience Fusion
→ Experience Memory
```

训练结束后冻结经验池，进入 held-out evaluation。

## 3. 全局原则

1. 向量召回、LLM 筛选和 initial rubric generation 不看 preference pair。
2. Generator 为每条 criterion 输出 1–10 的 `importance_score`，不负责归一化。
3. Judge、已有经验信用和 revision credit 都使用 Calculator 生成的 normalized weights。
4. 两次 revision attempts 都以同一个 $R_0$ 为起点；$R_2$ 不能从失败的 $R_1$ 继续修改。
5. Revision Generator 直接输出 ADD/DELETE/MODIFY，Revision Executor 用这些 operations 构造 revised rubric。
6. 只有 revision success 可以 Reflection 并分配 revision credit。
7. Revision Credit Assignment 同时完成 operation 收益计算和 candidate-operation binding。
8. Admission 在 provisional credit 之后执行；失败 candidate 的 credit 被丢弃，其他 candidate credit 不重新分配。
9. Operation log、binding 和 source trajectory 不提供给未来 selector 或 rubric generator。
10. Held-out evaluation 冻结经验池和 Beta 状态，不产生或回写经验。
11. 模型生成的面向人阅读文本（rubric 标准、critic 反馈、经验内容与 trigger 等）使用中文；字段名、ID、枚举等结构化协议值不翻译。

## 4. 生命周期

### Online Experience Learning

经验池从空集合开始：

$$
\mathcal{E}_0=\varnothing
$$

没有经验时，selector 输出空集合，generator 只根据 task 生成 rubric。第一次通过修订、反思、信用分配、准入和融合流程的经验自然成为经验池起点。

### Held-out Evaluation

训练结束后冻结：

```text
experience memory
alpha / beta / confidence
```

测试阶段关闭 exploration，不进行 revision-based experience growth，也不回写 downstream credit。

## 5. V1 范围

```text
Broad Vector Recall
+ LLM Selection
+ Boolean Rubric with 1–10 Importance Scores
+ Normalized-weight Judging and Credit
+ Initial Criterion-level Credit
+ Two Same-base Atomic-operation Revisions
+ Operation-bound Revision Credit
+ Post-credit Admission
+ MERGE / ADD Fusion
+ Beta-style Reliability
```
