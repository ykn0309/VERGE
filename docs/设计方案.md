# VERGE — 设计总览

VERGE（Verified Experience-guided Rubric GEneration）研究：

> 如何从 preference trajectory 中提炼 rubric-generation experience，并根据未来任务中的实际表现动态维护经验可信度，从而改善后续 rubric generation？

本文件只描述总体结构。每个模块的规则、公式和边界由对应子文档负责。

---

## 1. 总体流程

```text
Experience Memory
→ 向量广召回
→ LLM 经验筛选
→ Initial Rubric Generation
→ Rubric Judge
→ 已有经验信用分配
→ Reliability Update

如果 Initial Rubric 失败：
→ 最多两次、接续当前有效 rubric 的 Critic 反馈与 Generator 对话修订
→ Critic 输出私有 analysis 和公开 improvement_advice；公开建议追加到同一个 Generator 会话，生成完整 revised rubric
→ Revision Success 后 Reflection 生成 0–1 条候选（content + trigger）
→ Admission
→ Experience Fusion
→ Experience Memory
```

训练结束后冻结经验池，进入 held-out evaluation。

## 3. 全局原则

1. 向量召回、LLM 筛选和 initial rubric generation 不看 preference pair。
2. Generator 为每条 criterion 输出 1–10 的 `importance_score`，不负责归一化。
3. Judge 和已有经验信用 都使用 Calculator 生成的 normalized weights。
4. 第二轮接续最近有效 rubric；第一轮无效时仍以 R0 为基线。
5. Critic 输出私有 analysis 与公开 improvement_advice；仅公开建议追加到同一个 Generator 的单样本会话，由 Generator 完整修订当前 rubric。第二轮接续最近有效结果，无独立 Refiner 或原子操作；反馈隔离依赖提示词，不新增内容审核。
6. 只有 revision success 可以 Reflection；候选准入且合法融合后写入 0.25 折扣弱修订证据，不解释为因果贡献。
7. Reflector 最多生成一条候选，取消操作绑定及修订信用分配。
8. 候选直接 Admission；ADD 以 Beta(1,1) 为基础，MERGE 更新融合文本并继承旧信用；二者都追加弱修订证据并保存文本历史。
9. Reflector、Admission、Fusion 共用具体、条件性 rubric 设计机制定义；Admission 审核可用表达，不提前证明有效性。trigger 须支持指导范围与强度，单一机制可有协同动作；具体或限定任务类型本身不是缺陷。
10. Selector/Generator 区分任务操作与材料主题，任务目标与明确约束优先于经验；Operation log 和 source trajectory 不提供给未来 selector 或 rubric generator。
11. Held-out evaluation 冻结经验池和 Beta 状态，不产生或回写经验。
12. 模型生成的面向人阅读文本（rubric 标准、critic 分析、经验内容与 trigger 等）使用中文；字段名、ID、枚举等结构化协议值不翻译。

## 4. 生命周期

### Online Experience Learning

经验池从空集合开始：

$$
\mathcal{E}_0=\varnothing
$$

没有经验时，selector 输出空集合，generator 只根据 task 生成 rubric。第一次通过修订、反思、准入和文本融合/弱证据流程的经验自然成为经验池起点。

### Held-out Evaluation

训练结束后冻结：

```text
experience memory
alpha / beta / confidence
```

测试阶段关闭 exploration，不进行 revision-based experience growth，也不回写 downstream credit。

## 5. V1 范围

```text
Broad Vector Recall
+ LLM Selection
+ Boolean Rubric with 1–10 Importance Scores
+ Normalized-weight Judging and Credit
+ Initial Criterion-level Credit
+ Two Sequential Generator Dialogue Revisions
+ Neutral Base Prior + Discounted Revision Evidence + Downstream Credit
+ Admission before Fusion Evidence
+ MERGE / ADD Fusion
+ Beta-style Reliability
```
