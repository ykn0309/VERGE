# v3.1在线聚类

2026-11-13 · 目标算法，未实现或验证。原始边定义与主流程见[方法设计](../设计方案.md)。

## 1. 对象与相似度

文本向量由嵌入模型生成，任务使用task，经验使用三个正文字段；不输入标签、回答或收益。单位向量余弦裁剪到[0,1]得到T。

对对象x，按当前对侧类别g汇总具体关联对象数并归一化：

```text
n_x(g) = x关联到对侧类别g的不同对象数
p_x(g) = n_x(g) / Σ_h n_x(h)
J_group(x,y) = Σ_g min(p_x(g),p_y(g)) / Σ_g max(p_x(g),p_y(g))
S(x,y) = (1−w) × T(x,y) + w × J_group(x,y)
```

任务按经验类汇总，经验按任务类汇总。任一对象无关联时仅用T，不将未知写成零分布。总次数不同但比例相同的分布相似度为1；关联数量作为独立证据保留，w如何结合证据量尚待确定。

对象到组的相似度取与组内其他成员S的平均，排除自身。每个对象唯一归属，无达标组时独立建组；任务与经验各设门槛，不预设组数。各半轮的具体移动策略、平分规则等需实现前确认，不宣称这是有收敛证明的优化。

## 2. 在线交替更新伪代码

```text
UPDATE(new_objects, new_provision_edges, state):
    保存固定文本向量与去重提供边（不含来源候选验证）
    仅用文本为新对象形成初始归属，已有对象保留当前归属
    for round = 1 ... 5:
        before = 保存两侧归属快照
        # 此半轮固定经验类别
        task_profiles = 按当前经验类别汇总并归一化任务关联
        更新任务分组(task_profiles, text_vectors, task_threshold)
        # 此半轮使用更新后的任务类别
        experience_profiles = 按当前任务类别汇总并归一化经验关联
        更新经验分组(experience_profiles, text_vectors, experience_threshold)
        if 两侧归属与before相同:
            保存状态，标记本次稳定，返回
    保存状态，标记达到上限；仍有移动时未稳定
```

两侧类别变动后重新汇总分布、刷新相关相似度，不能继续使用v3固定对象集合对应的缓存值。在线沿用已有状态，不每题重新初始化全部对象；推理查询不改变状态。

## 3. 边界

同题最多三条经验各自单独试用，因此最多三条提供边；共同任务表示同题尝试过，不证明组合收益。经验组经任务聚类间接影响历史组织，不作为候选硬边界或经验组收益排序对象。

对侧全部单成员时汇总未必带来更多共享信息；分组错误也可能相互强化。新任务无关联时仍按文本匹配历史组，改类别关联不保证命中增加。权重、门槛和初始化需要验证，分组变少不等于质量改善。
