# v3.1在线聚类：最低相似度约束与整体优化

2026-11-13 · 已实现并完成离线约束测试，尚未用真实任务验证效果。**不预设组数；低阈值排除明显不合理的合组，整体得分决定其余分组。单成员始终合法。**关联权重沿用原公式，最低阈值初值已确认：任务0.35、经验0.50。数据边界见[方法设计](../设计方案.md)。

## 1. 输入与相似度

对侧类别固定时，分别处理一种对象集合V（任务或经验）。输入为固定文本向量、具体任务—经验提供边、对侧类别、已有本侧划分及最低阈值τ。任务和经验分别使用τ_task、τ_exp，均在(0,1]内配置，不设输出组数K。

任务文本为task，经验文本为三个正文字段；不输入回答、标签或收益。文本相似度T为单位向量余弦裁剪到[0,1]。对对象x，按当前对侧类别g汇总原始关联对象数：

```text
n_x(g) = x关联到对侧类别g的不同对象数
p_x(g) = n_x(g) / Σ_h n_x(h)
J(x,y) = Σ_g min(p_x(g),p_y(g)) / Σ_g max(p_x(g),p_y(g))
S(x,y) = (1−w_xy) × T(x,y) + w_xy × J(x,y)
```

任一对象无关联时S＝T，不构造零分布。用户已确认沿用对称证据量权重：`w_xy=0.5*m/(m+1)`，其中m为两个对象原始关联对象数的较小值，不是关联类别数。归一化分布描述使用模式，不是适用概率或收益，原始关联数量另存。

## 2. 合法划分与最低约束

划分P将全部对象分成若干非空且互不重叠的组，每个对象只属于一组。对组C定义：

```text
a(x,C) = Σ_{y∈C且y≠x} S(x,y) / (|C|−1)    （|C|>1）
F(C) = true                                （|C|=1）
F(C) = [对每个x∈C，a(x,C) ≥ τ]             （|C|>1）
```

P合法，当且仅当其中所有组满足F。**检查每个成员的平均，不只检查全组总平均**，防止强联系多数掩盖弱联系成员。单成员不需要相似度自证，不因组数多被强制吸收。

两个非空组的跨组平均定义为：

```text
b(C,D) = Σ_{x∈C,y∈D} S(x,y) / (|C|×|D|)
```

合并要求b(C,D)≥τ，且合并后的每个成员也满足F。加入单个对象等价于检查b({x},D)，随后检查受影响组的完整合法性。达到τ只表示允许尝试，不表示必须合并。

该约束保护的是成员平均联系，不要求组内任意一对都≥τ。即使a达标，仍可能存在低于τ的个别成员对；若要求每一对都达标，将是另一种更强约束，本设计不作此承诺。

## 3. 整体分组目标

令完整对称权重矩阵A为S，A_ii＝0；不按τ删边，也不使用top-k邻居。τ限制可接受的划分／动作，不改变整体得分所看到的背景关系。

```text
k_i = Σ_j A_ij
2m = Σ_i k_i
Q(P;A) = Σ_ij [A_ij − k_i*k_j/(2m)] × I(i,j同组) / (2m)
```

使用经典加权模块度，固定分辨率γ＝1。目标为：

```text
在所有合法划分P中，寻找Q(P;A)较高的结果。
```

组内实际联系相对总体联系预期越突出，Q越高。采用标准模块度是明确的目标选择，不等于没有尺度偏好。**最低约束负责拒绝弱联系，Q负责从合法分法中比较整体结构**，二者缺一不可。

空集合返回空划分；一个对象保留单组。总权重为0时全为单成员，不计算除零公式；零度对象保持单成员。完整矩阵空间O(|V|²)，搜索成本受候选动作数量影响。

## 4. 单侧优化规则

### 4.1 起点与合法性修复

每个固定矩阵A下，尝试以下起点：

1. 已有划分，加新对象单成员；若不合法，先按下述规则修复。
2. 全部对象独立成组。
3. 全部对象同组，但仅在F(V)成立时纳入，禁止用非法大组参与得分竞争。

修复只在开始优化前进行：对每个不合法组，移出a最低的成员成为单成员，直至剩余组合法；平分按稳定对象ID。修复不要求Q提高，因为矩阵改变后旧分组可能已违反硬约束。记录移出对象及原因；该规则是确定性的修复方法，不保证最少移出成员或最优修复。

### 4.2 对象移动

按固定对象ID顺序，对x当前组C，枚举移入每个其他组D或新建单成员组：

- 移入现有组先要求a(x,D∪{x})≥τ；新单成员不需门槛。
- 移出后的C\{x}（若非空）及目标组均须满足F，其余组保持不变。
- 仅执行ΔQ＝Q(P')−Q(P)>0的合法动作；多个动作时取ΔQ最大者，平分按目标成员ID规范序。与留在当前组同分则不动。

如果移出使剩余组不合法，该移动不能执行，不能悄悄留下不合法原组。一个对象独立成组是候选动作，不强制要求所有对象都加入多人组。

### 4.3 组间合并与停止

完成对象移动一轮后，枚举所有组对(C,D)：先检查b(C,D)≥τ及F(C∪D)，再计算ΔQ。执行最大正增益合并并回到对象移动；没有合并且整轮无移动时停止。

每个起点均按同一规则搜索，返回最终Q最高的合法划分；同分优先选择与原有划分共同成员关系变化最少者，再按成员ID规范序确定。比较关系变化而不是组编号，组ID重命名不影响结果。

在固定A、精确算术下，正增益操作不会重复划分，因此有限搜索可终止；实现浮点容差只处理计算误差，不代替τ。若设置计算预算，耗尽则保留最好合法结果并标记未完成。算法只搜索单对象移动、独立成组及组合并，不保证全局最优、任意多成员拆分最优或唯一语义正确。

```text
PARTITION(S, previous, τ):
    A = S，主对角线置0
    if 对象数≤1或没有正权: return 单成员划分, degenerate
    seeds = {所有对象独立}
    if previous存在: seeds加入 REPAIR(previous加新对象单成员, S, τ)
    if F(V): seeds加入 {V}
    for P in 去重后的seeds:
        repeat:
            moved = false
            for x in 稳定ID顺序:
                枚举移入现有组或新单成员的动作
                拒绝相似度不达标或受影响组不合法的动作
                if 最大合法ΔQ > 0: 执行动作; moved = true
            枚举满足跨组门槛及合并组合法性的合并动作
            if 最大合法合并ΔQ > 0: 执行合并; continue
            if not moved: break
        保存最终合法P及其Q
    return 按Q及平分规则选择的划分
```

## 5. 双向在线更新

首次分组分别以文本相似矩阵调用PARTITION，提供文本初始归属。在线新增对象时，保留旧类别，新对象先独立；以文本决定新对象能否进入其他组，动作同样须保持受影响组合法并提高文本矩阵Q，随后才开始混合关系更新。此阶段不以文本重分全部旧对象，也不宣称初始化是全局最优。

一个外层轮次由两个半轮构成：

```text
UPDATE(state, new_objects, new_edges):
    保存固定向量与去重原始提供边（排除来源候选验证）
    首次用文本分组；在线以文本初始化新对象
    seen = {两侧按成员集合规范化后的划分}
    for round = 1 ... 5:
        old = 两侧划分规范表示
        固定当前经验类别
        汇总任务类别关联分布，构造任务S_T
        P_T = PARTITION(S_T, 当前P_T, τ_task)
        固定更新后的任务类别
        汇总经验类别关联分布，构造经验S_E
        P_E = PARTITION(S_E, 当前P_E, τ_exp)
        signature = 两侧划分规范表示
        if signature == old: 返回stable
        if signature in seen: 返回cycle及循环记录
        seen.add(signature)
    返回round_cap及未稳定标记
```

每个半轮固定对侧类别和本侧S，本侧移动后不重算本侧S，只更新Q涉及的组统计。切侧时重新汇总分布并刷新分数，不能复用旧的类别关联分数。

对侧变化会改变S和合法性，因此每个半轮先修复本侧分组。一次完整轮次结束时，任务划分只保证对其任务半轮所用的经验类别合法；若经验随后变化，需要下一任务半轮复查。stable时两侧同时对应当前对侧；cycle或round_cap的快照需标记最后检查所用的对侧版本，不能冒称双侧最终约束均已同步满足。

固定矩阵内Q增加不代表跨半轮的联合目标增加，可能振荡；检测循环与5轮上限是终止规则，不是收敛证明。

## 6. 输出与边界

输出每个对象唯一归属、组成员、各组最小成员平均相似度、Q、τ与w设置、更新轮数、修复记录及stable／cycle／round_cap／budget状态。稳定时每个多人组均满足其当前矩阵的成员平均门槛；未稳定时保留对应矩阵版本供核对。

关联仍表示独立任务实际提供过经验。同题最多3条分别试用可以有3条边，来源候选验证不入图，收益不参与聚类边权。类别变化后按原始任务ID重汇总收益，不复制或继承。

阈值是低限保护而非目标组数控制器，数值需根据新S分布与内容审查确定，不能直接把0.75重新命名为低阈值。成员达到低限但没有正ΔQ时也不合组；联系弱但超过低限的对象仍可能加入，故低限本身需要验证，不能承诺消除全部错误合组。

新任务按文本相似度查询前3个任务组，不设查询门槛；分组合并低限仍保留，候选配额不变。文本表示、选择偏差、模块度尺度与计算成本仍影响结果；单成员比例或Q增大均不等于任务效果改善。

理论目标参考[加权模块度定义](https://networkx.org/documentation/stable/reference/algorithms/generated/networkx.algorithms.community.quality.modularity.html)与[Newman 2006](https://arxiv.org/abs/physics/0602124)。最低约束、修复、在线初始化及双向交替为本项目设计，尚无v3.1真实数据有效性验证。

## 7. 已确认参数与初值依据

2026-11-13用户确认沿用上述w公式，并采用初值τ_task＝0.35、τ_exp＝0.50。这是已确定的初始设置，不是已实测验证的最佳值。

依据是对原500题检查点的只读分数计算：保留原499任务、169经验的向量、提供边及最终类别，用新类别分布J和已确认w计算S，没有重新分组或调用模型。

| 对象 | 成对S中位数 | 最近邻S中位数 | 已确认低限 | 达到低限的对象对比例 |
|---|---:|---:|---:|---:|
| 任务 | 0.1457 | 0.4466 | 0.35 | 2.08% |
| 经验 | 0.4370 | 0.7073 | 0.50 | 30.68% |

任务中62／499个对象的最相近对象也低于0.35，经验中3／169个低于0.50；在该固定S下它们不能满足任何多人组的成员平均低限。对比0.75时分别为472／499及131／169。上述是分数诊断，不是新聚类结果；满足成对低限不代表能加入某多人组，更不代表合组会提高Q或内容合理。

两侧初值不同是因为对象文本和分布尺度不同；实际类别交替更新后S会变化，不能将这些统计直接当新算法的结果。后续需检查错误合组、应合未合和稳定性，不以单成员减少作为唯一成功标准。原检查点及日志未改。
