# 经验记忆（Experience Memory）

> 上位文档：[VERGE 设计总览](../设计方案.md)

## 1. 模块职责

Experience Memory 只负责保存可复用经验及其累计证据，不负责经验生成、准入、信用分配或融合决策。

经验是“如何生成好 rubric”的方法原则，而不是具体 criterion。

## 2. Experience 结构

```text
Experience {
    id
    content
    trigger
    alpha
    beta
    confidence
    source_trajectories
    evidence_history
}
```

示例：

```json
{
  "id": "exp_001",
  "content": "当任务包含多个可独立验证的要求时，应将它们拆成独立的 Boolean criteria。",
  "trigger": "Task 同时包含多个可以独立判断的显式要求。",
  "alpha": 2.20,
  "beta": 1.25,
  "confidence": 0.638,
  "source_trajectories": ["sample_103", "sample_287"],
  "evidence_history": [
    {
      "sample_id": "sample_103",
      "evidence_type": "revision_credit",
      "credit": 0.45,
      "evidence_weight": 1.0
    },
    {
      "sample_id": "sample_287",
      "evidence_type": "revision_credit",
      "credit": 0.08,
      "evidence_weight": 1.0
    },
    {
      "sample_id": "sample_421",
      "evidence_type": "downstream_credit",
      "credit": 0.67,
      "evidence_weight": 1.0
    },
    {
      "sample_id": "sample_518",
      "evidence_type": "downstream_credit",
      "credit": -0.50,
      "evidence_weight": 0.5
    }
  ]
}
```

## 3. 字段含义

- `content`：可迁移的 rubric-generation principle；
- `trigger`：经验适用的任务条件和边界；
- `alpha`、`beta`：累计正负 evidence；
- `confidence`：$\alpha/(\alpha+\beta)$；
- `source_trajectories`：产生或再次发现该经验的 sample IDs；
- `evidence_history`：revision credit 与 downstream credit 的样本级记录，每条仅包含 `sample_id`、`evidence_type`、`credit` 和 `evidence_weight`；不记录 `source_id` 或 `source_criterion_ids`。

`source_trajectories` 和 `evidence_history` 不提供给 rubric generator。

## 4. Selector View

Retrieval selector 只允许看到：

```text
id
content
trigger
confidence
evidence amount
```

它不能看到：

```text
source trajectories
operation logs
experience-operation bindings
具体 preference pair
```

## 5. Reliability 字段归属

Experience Memory 只存储 `alpha`、`beta` 和派生的 `confidence`，不定义其更新规则。

- initial rubric 的 downstream credit：见[已有经验信用分配](./05-已有经验信用分配.md)；
- revision credit 与 Admission：见[修订信用分配与准入](./09-修订信用分配与准入.md)；
- Beta 更新和 evidence weighting：见[可靠性更新](./11-可靠性更新与噪声证据.md)。

## 6. 模块边界

本模块不决定：

- 候选经验是否合格；
- 候选经验对应哪些 revision operations；
- 候选经验执行 MERGE 还是 ADD；
- 哪条经验应被当前 task 使用。
