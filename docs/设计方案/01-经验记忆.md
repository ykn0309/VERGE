# 经验记忆（Experience Memory）

当前Memory5，见[计划61](../plans/61-延迟归纳与正负案例经验更新.md)。Experience保存ID、content/trigger、alpha/beta、source_trajectories、evidence_history、cases、text_version和update_history；不再有父子关系、退役或继承信用。

confidence=alpha/(alpha+beta)，初始Beta(1,1)。正向、反向及同判轻负信用即时分别累计；不折扣、不先抵消。信用无10次上限。cases最多10个不同sample_id，初始候选原题占1条；每条保留完整任务/两回答、实际source_id/文本/版本、rubric/Judge/P/N及候选可选分析。案例必须具有实际非零来源信用，source_trajectories与案例IDs一致；原题须满足候选净正资格。

原题不计下游窗口，自上次成功归纳后每3个不同下游案例触发更新，第10条强制最后尝试。成功保留原文也重置，失败不重置但同一案例不重复尝试。达到10条之后文本和案例冻结，信用继续累计。单条改写保持ID和Beta，文本变化才version+1。

update_history保存触发样本、全部案例IDs、前后文本/版本及error；实际使用版本不可改写。pending_feedback_count与update_due由有限案例及更新历史派生，不额外存重复计数。all返回独立副本。Generator/Selector不见案例，更新后向量文本缓存失效，当前样本固定E不变。

Memory5与Trajectory/Manifest7拒绝旧协议，不迁移或跨协议resume；历史实验文件保留。held-out禁止所有写入。Memory与trajectory不是跨文件事务，resume必须核验全部信用及案例不超出完整前缀。
