# 经验记忆

当前Memory6，见[计划65](../plans/65-原子经验类别检索与同判独立记录.md)。

小经验保存独立ID、content/trigger、alpha/beta、来源案例、实际使用记录、文本版本与归纳历史，以及可空的category_id。每条仅表达一种可独立采用/忽略的核验方法；不通过额外模型或规则判定语义原子性。

类别仅有稳定ID、名称和描述；成员归属保存在小经验category_id，无类别信用，不改成员正文或合并信用。未分类小经验仍为独立检索单位。分类方案可以调整全部归属，每条经验恰好分配一次；新类别由程序分配ID，现有类别沿用ID，空类别删除。

Memory同时持久保存pending_organization（经验ID到最新文本版本）和organization_history。入池或正文/trigger变化入队，按不同经验去重；信用变化不入队。默认5条，在样本收尾整理；训练完成/暂停时处理剩余队列。失败保留原归属及队列，同一待整理版本不重复调用，有新入池/文本变化时可再次尝试。收尾调用使用最后一个已完成训练sample_id记入Memory历史，样本内调用也记入trajectory。

confidence=alpha/(alpha+beta)，初始Beta(1,1)。正确/反向区分分别累计P/N；双方满足和双方不满足分别保存UsageRecord标准计数，不改Beta、不进入归纳、不占容量。usage_history包含来源实际应用和后续R0，记录实际文本版本；区分率仅展示，不提供给Selector。

cases最多10个不同sample_id，来源占1条。仅收录存在正向/反向数值证据的实际应用；混合案例完整轨迹保留，归纳输入过滤同判标准。原题不计窗口，每3个不同下游案例归纳；成功含保留原文均重置，失败保留窗口，同题不重复尝试。第10条最后尝试，之后冻结案例/正文、继续信用与使用计数。无拆分、父子、MERGE或信用继承。

all/get/categories返回独立副本；held-out禁止全部写入。旧协议不迁移，历史文件保留；resume验证代码/配置/提示词/数据及完整前缀，信用、使用和分类事件不能越界。Memory和trajectory仍不构成跨文件事务。
