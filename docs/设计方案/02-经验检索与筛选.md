# 经验检索与筛选

> 上位文档：[VERGE 设计总览](../设计方案.md)
>
> 输入：[Experience Memory](./01-经验记忆.md) ｜ 输出：[Initial Rubric Generation](./03-初始Rubric生成.md)

## 1. 模块职责

从经验池中为当前 task 选择少量适用经验。流程分为向量广召回与 LLM 筛选。

## 2. 向量广召回

根据 task 与经验 `content + trigger` 的语义相似度召回候选：

$$
\mathcal{C}_t=\operatorname{TopL}_{e\in\mathcal{E}}Sim(x_t,e)
$$

V1 固定：

$$
L=20
$$

经验池为空时：

$$
\mathcal{C}_t=\varnothing
$$

广召回只负责尽量找全，不直接决定最终经验，也不混合 similarity 与 confidence 形成线性总分。

## 3. LLM 筛选

Selector 输入：

```text
current task
candidate content
candidate trigger
candidate confidence
candidate evidence amount
```

Selector 首先区分指令要求执行的任务操作与输入材料讲述的主题，以任务目标、明确约束和实际输入条件判断经验的适用性。材料主题相似本身不足以选中；指导强度必须与当前条件匹配。

Selector 对每条候选按以下顺序判断：

1. **只用当前 task** 核对 trigger 的所有条件是否成立；无法从 task 核验、条件不成立或需要借助未来回答/判断结果时，不得仅凭题面关键词相似就选中；
2. 经验能否为该任务的 rubric 提供**具体、可执行且并非 task 本身已经充分说明**的生成帮助（新增判断问题，或实质改变原本会如何判断）；如果只重复 task 已足以推出的标准而没有其他增益，则不选；
3. 多条经验是否互补而非重复、冲突；
4. **仅在适用性和生成帮助相近时**，用 confidence 与 evidence amount 辅助排序。高信度不能弥补 trigger 不匹配。

输出：

$$
E_t\subseteq\mathcal{C}_t,
\qquad 0\le|E_t|\le5
$$

可以少选或不选，不能为了凑数加入无关经验；不设单独的 confidence 硬门槛，也不因本规则降低 0–5 的选择上限。

## 4. 冲突经验

如果候选中存在相互冲突的经验，Selector 不能同时选择它们。选择顺序为：

1. 先排除 trigger 不成立或没有具体生成帮助的经验；
2. 在剩余适用经验中比较 task 匹配与具体帮助，高信度不覆盖不适用；
3. 对同样适用的候选参考 confidence、evidence amount 及训练阶段的有限 exploration。

## 5. Exploration

训练阶段最多保留一个 exploration slot，用于选择“相关但 evidence 较少”的经验。不得探索明显无关的经验。

Held-out evaluation 关闭 exploration。

## 6. 隔离边界

Selector 不能看到：

```text
chosen/rejected
preference label
judge results
critic feedback
revision operations
source trajectories
```

经验被召回或选中本身不产生任何 confidence update。
