# 经验检索与筛选

当前见[计划65](../plans/65-原子经验类别检索与同判独立记录.md)。只读取task与经验公开视图，不看偏好对、Judge、来源轨迹或案例。

## 检索单位

未分类小经验作为独立单位，向量文本为content和trigger。已分类经验不单独嵌入，整个类别作为一个单位：名称、描述、全部成员trigger/content共同嵌入，不带程序ID、信用或案例。成员或类别文本变化自动使缓存失效；信用变化不重新嵌入。

按余弦相似度召回Top20单位，结果可混合类别与未分类经验；命中类别完整展开全部成员。20不是展开后的经验上限，不静默截断成员。空池不调用Embedding，Fake检索按稳定单位顺序取前20。

## Selector

同一次调用接收按类别组织的全部召回成员和未分类经验。类别展示名称/描述及所有成员；每条成员有短经验编号、content/trigger、confidence和evidence_amount。最终仅输出0到5条小经验ID，可以选同类的任意子集，不输出类别ID、不强制整类采用。

先看trigger及实际任务是否匹配，再看是否对标准设计有具体帮助；主题相似或高置信度不替代适用性。避免重复/冲突，只在适用性与帮助相近时参考历史证据。未选或未引用不记信用；不设置探索名额、信用门槛，不提供区分率。

完整system/user输入默认100000 UTF-8字节，可通过modules.selection.config.input_bytes配置。超预算记录该样本错误并继续，不截断类别、不增加筛选调用。来源只允许已召回的小经验ID；类别ID和长程序ID不进入输出引用。

输出E在本样本R0和后续应用中固定列表及文本；Generator只看小经验ID/content/trigger，不看类别或历史可靠性数值。分类与经验文本更新都在候选流程结束后进行，held-out冻结全部池数据。
