# 无阈值、无预设组数的自动分组（候选）

2026-11-13 · 按用户请求设计，尚未采用、实现或用真实数据验证。不替换当前规范中的聚类部分，待讨论后决定。目标是不指定组数K、相似度准入阈值τ或邻居数k；其余文本与类别关联融合权重仍是独立设计参数。

## 1. 基本思路

保留文本＋归一化类别关联相似度S。把所有同类型对象的成对相似度作为非负权重，使用经典加权模块度评价整个划分：组内联系应强于由全体对象联系强度推算的预期联系。移动或合并只有提高整体得分才接受，组数随搜索自然变化。

借用的是社群划分的目标函数，不强制指定Leiden或Louvain求解器，也不宣称这是新的模块度定义。下述搜索为可复现的基础候选，不能保证全局最优或语义真值。

## 2. 关系矩阵与整体目标

任务和经验分别构建对称矩阵：

```text
A_ij = S(i,j), i ≠ j
A_ii = 0
k_i = Σ_j A_ij
2m = Σ_i k_i
B_ij = A_ij − k_i*k_j/(2m)
Q(P) = Σ_ij B_ij * I(i,j属于同组) / (2m)
```

保留所有正权，不按0.75截断，也不取top-k邻居。数学上等价于一个完整加权关系图，存储上不必使用图框架。零权无需建立连接。

`k_i*k_j/(2m)`是保留对象总联系强度的随机基准。普遍与谁都相似的对象，不会仅因绝对相似度高就促使所有对象合并；相对背景更紧密的局部关系才支持分组。

采用经典模块度，即分辨率γ固定为1，不引入待调的社群粒度参数。这是明确的尺度约定，不代表无模型假设或“算法没有任何参数”。单侧无对象返回空划分；只有一个对象保留单组；总权重为0时各自独立，不能用除零公式猜测关系。其他零度对象独立保存，Q不决定其语义归属。

全部放一组时Q＝0（总权重正），不是天然最优；全部单成员也不是天然最优。均匀关系可以输出一个组，没有额外规定必须出现多个类。

## 3. 单侧划分搜索

固定本次A后，分别从三种初始划分搜索：已有划分（新对象先独立）、全部单成员、所有正度对象同组。首次文本分组没有已有划分时只用后两种。它们是搜索起点，不是指定输出组数。

每个初始划分执行：

1. 按固定对象ID依次检查，将对象放到每个现有组或一个新单成员组，计算ΔQ；执行得分最高且ΔQ>0的移动。移动立即生效，空组删除。
2. 完成一轮后，对所有组对计算合并ΔQ，执行最大的正增益合并，再返回对象移动。
3. 没有任何正增益移动和合并则结束。移出到新单成员组及其他组可以拆开原组；多起点避免只靠已有归属。但这不是任意多节点拆分的完整搜索。
4. 比较不同起点的最终Q，返回最高者。Q相同时优先选择相对已有划分变化少的结果；仍同分时按成员ID规范序确定。无已有划分时直接用规范序。单次ΔQ平分按目标组成员ID规范序确定，不用新生成的组编号改变优先级。

严格提高Q和有限种划分保证固定A下的精确算术搜索终止；实现可设置操作预算并记录未完成。浮点容差仅防数值抖动，不能冒充人为相似度门槛。返回组数即最终非空组数。

```text
PARTITION(A, previous):
    if 没有正权: return 每对象独立, no_relational_signal
    seeds = {全单成员, 全正度对象同组, previous加新对象单成员(如有)}
    for P in seeds:
        repeat:
            moved = False
            for x in 固定ID顺序:
                action = 在所有现有组及新单成员组中找最大ΔQ移动
                if ΔQ(action) > 0: 执行action; moved = True
            merge = 所有组对中最大ΔQ合并
            if ΔQ(merge) > 0: 执行merge; continue
            if not moved: break
        保存P及Q(A,P)
    return 得分最高的候选划分（按约定处理平分）
```

允许迁移、新组出生及合并，不需要为每个动作再指定相似度阈值。这里只自动选择搜索到的较优划分，不对“最佳”作无限保证。

## 4. 双向在线更新

初次启动在两侧文本相似矩阵上分别运行PARTITION，得到类别归属。新增对象时先用文本信息为两侧新对象建立初始类别，再进行以下交替更新，避免对侧新对象没有归属：

```text
UPDATE(state, new_objects, new_edges):
    保存原始对象、固定向量与去重提供边
    用文本矩阵初始化新增对象；已有类别作为搜索起点之一
    seen = {两侧按成员集合规范化的当前划分}
    for round = 1 ... 5:
        old = 当前两侧划分
        固定经验类别，计算任务的类别关联分布和混合矩阵A_T
        task_partition = PARTITION(A_T, 当前任务划分)
        固定新任务类别，计算经验的类别关联分布和混合矩阵A_E
        experience_partition = PARTITION(A_E, 当前经验划分)
        signature = 两侧划分规范表示
        if signature == old的规范表示: 返回stable
        if signature in seen: 返回cycle，保存当前结果及循环记录
        seen.add(signature)
    返回round_cap，保存最后结果及未稳定标记
```

比较成员集合而非组编号判断稳定，避免重编号误判振荡。局部PARTITION每次只比较同一个固定矩阵上的Q；切换对侧类别会改变矩阵，因此不能把两次不同矩阵的Q直接相比，也没有两侧联合全局目标单调上升的保证。检测循环和最多5轮用于诚实终止，cycle不当作收敛。

旧反馈仍按原始任务ID保存，分组更新后重新汇总，不继承或复制收益。同题最多三条分别试用的提供边及来源排除规则不变，聚类不使用Judge标签或收益作边权。

## 5. 检索、代价和效果边界

本候选只取消分组准入门槛与预设组数。新任务检索历史组是另一问题，现有查询门槛不会因为换分组目标自动消失；是否改为直接取文本最相近的最多3组需要另行讨论，不自动采用。

完整矩阵空间为O(n²)，朴素枚举所有移动／合并的计算成本也可能较高；新边和类别变化可影响远端对象，不能保证只改局部就等价于完整搜索。在线指沿用已有状态不断更新，不保证常数时间或完整增量最优。

经典模块度有自身尺度偏好，可能遗漏小而有意义的类；无阈值不意味着所有任务必能正确归类。文本向量若不能表达评分需求、错误选择若污染关联，换目标函数不能自动修复这些输入。未设τ和K，但仍有S的融合权重、固定γ＝1、初始搜索集合和计算预算。

可核对的数值例子：四对象A／B／C／D，A-B与C-D权重0.8，跨两对权重均0.1。全部同组Q＝0，全单成员Q＝−0.25，{A,B}/{C,D}的Q＝0.30。将所有权重同时减半，Q不变，不因绝对分数低于0.75就拒绝这两组。此例只解释公式，不证明真实语义分组效果。

## 6. 验证与研究依据

先在固定矩阵检查Q、移动增益、孤立节点、均匀关系、在线合并／拆开及循环记录，再在保留的真实轨迹上只读回放，审查遗漏合并、错误合并、组稳定性及后续选择覆盖。分组变少、Q增加不等于偏好评判改善；需要独立验证收益。

整体目标使用已知的[经典模块度定义](https://networkx.org/documentation/stable/reference/algorithms/generated/networkx.algorithms.community.quality.modularity.html)，理论背景见[Newman 2006](https://arxiv.org/abs/physics/0602124)。多起点局部搜索、原有混合表示与两侧交替的组合是本项目候选设计，不借论文为其在线收敛、泛化或最优性背书。
