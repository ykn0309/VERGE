# 已有经验信用分配

当前见[计划65](../plans/65-原子经验类别检索与同判独立记录.md)。已有小经验只从训练R0记账；有效Judge后、整体成败分支前立即更新，后续失败不撤销。R1/R2中的已有经验引用仅审计。

对标准i，令d_i=J(chosen,c_i)−J(rejected,c_i)，来源集合S_i，归一化权重w_i：

- 正确区分：P(e) += w_i/|S_i|，N不变。
- 反向区分：N(e) += w_i/|S_i|，P不变。
- 同判：P/N均不变，分别记录双方满足或双方不满足的标准次数。

没有来源的标准参与整体评分，不分配经验信用；多来源均分，同一经验的正负部分不先抵消。P+N不超过1，跨经验的数值证据总量等于有来源且有区分的标准权重之和。精确十进制比例用于候选P>N资格，不以浮点误差判定。

alpha+=P，beta+=N，无折扣、lambda或margin增益。P+N=0不追加EvidenceRecord；引用同判仍追加独立UsageRecord。记录实际使用版本；信用与计次按小经验归属，类别不记账。来源为模型自报，不能解释为因果贡献。

仅有正向/反向数值证据的R0案例进入最多10条有限案例与每3个不同任务归纳窗口；同判不占容量、不参与归纳。混合案例的归纳投影仅保留有区分的相关标准，完整rubric/Judge仍保存。held-out不写信用、使用计数或案例。
