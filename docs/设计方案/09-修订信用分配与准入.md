# 候选经验生命周期

> 路径保留。Admission模型和Fusion/MERGE已删除；实施见[计划48](../plans/48-局部正向准入与有限样本经验更新.md)。

每轮Critic提出0–1条候选，最多两轮。候选原文直接进入独立Generator(task+固定E+当前C)，自主采用；第二轮只替换C，不累计C1。Critic保持样本内多轮消息历史。

Judge有效后，按本轮引用候选的标准计算P/N。采用且自身P>N则eligible=true，不要求整体成功；P=N或P<N不具资格。正负分别记账，净方向只控制资格，不能用P−N替代alpha+=P、beta+=N。

合格候选暂存，本样本正常结束后最多新增一条：C2合格优先C2，否则回退合格C1；都不合格无新增。整体成功结束轮次；整体失败且有预算则继续。第二轮空候选或提案/生成格式结构耗尽可回退C1。未选候选保留实际轨迹但不记入池信用。

Judge错误/角色拒答结束属于错误收尾，不做新候选回退入池；真实有效C1留档。网络/鉴权、存储和程序错误fail-fast。已有合法R0信用不回滚。

被选候选直接新增，保留实际应用原文和来源案例，Beta从(1,1)追加自身P/N；不调用Fusion，不MERGE。入池记录与整体判别状态分开，整体失败可以有入池，整体成功可以无入池。

来源引用是模型自报，不证明忠实落实或因果贡献。局部正向信用不保证经验通用、Judge正确或新文本已验证。已有经验的后续文本归纳见[经验更新](10-经验融合.md)。
