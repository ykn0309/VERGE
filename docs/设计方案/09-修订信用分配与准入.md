# 候选经验准入（取消修订信用分配）

> 上位文档：[设计总览](../设计方案.md) ｜ 输入：[经验反思](./08-经验反思.md) ｜ 输出：[经验融合](./10-经验融合.md)

## 当前方法

成功修订后 Reflector 生成 0–1 条候选，仅包含 content、trigger。取消操作绑定、operation contribution、evidence budget 和暂定修订信用分配步骤；修订成功不直接证明总结出的经验有效。

候选直接进入 Admission。模型只看 task 和候选 content/trigger，审核原则是否单一、明确、可迁移，trigger 是否仅凭未来 task 可核验。可迁移意味着同类任务间复用，不要求对所有领域适用。

返回 decision（PASS/FAIL）和具体 reason。FAIL 候选不入池；PASS 交给 Fusion。准入不产生信用，不自动改写候选。

新增经验使用 Beta(1,1)，置信度 0.5；MERGE 保留已有经验的 Beta 和 evidence_history，只追加来源。唯有后续任务 R0 中的实际 downstream credit 才更新置信度，公式见 [已有经验信用](./05-已有经验信用分配.md)。

本文件路径沿用以避免已有文档链接失效；旧修订信用公式不再是当前方法。
