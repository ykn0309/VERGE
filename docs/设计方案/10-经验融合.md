# 经验新增、重新归纳与类别整理

当前见[计划65](../plans/65-原子经验类别检索与同判独立记录.md)。路径保留用于链接；没有Fusion、MERGE或拆分。

候选实际引用且自身P>N才有资格，正常样本结束最多新增一条，合格C2优先否则C1；不要求整体成功。保存实际原文、来源案例、对应信用和使用计数，新小经验进入待整理队列。

已有小经验的正向/反向实际使用案例共同占用包含来源的10条上限。原题不计窗口，自上次成功归纳后每3个不同下游任务归纳；不要求最后一个任务正向。成功包括合法保留原文，失败不重置、同一新案例不重复尝试。第10条最后尝试，之后冻结正文/案例、继续信用和计次。同判不参与归纳，不占额度或窗口。

归纳输入discriminating_cases_v4：当前经验，有限案例的完整task/chosen/rejected，以及仅引用当前经验且有区分的标准问题、两侧Boolean/reason、feedback=positive/negative。当时使用文本不同才附applied_experience。不提供P/N、权重、共享来源数、其他标准、整体结果或Critic分析；短案例编号，不截断回答。

归纳员只返回content/trigger，修正当前这一种原子方法及其适用范围，不追加其他可独立采用的方法、不提新候选、不新增analysis或审核调用。新方法仍由正常Critic候选流程提出。150/60字符仅提示词约束，不校验长度。保留ID/Beta，文本变化版本+1并进入待整理队列。

类别整理默认每5条不同待整理经验一次，参数modules.application.config.organization_batch_size；样本结束执行，训练完成/暂停处理不足5条的剩余。输入全部小经验content/trigger/当前归属、现有类别名称/描述、待整理ID；不看信用或样本。输出完整分类方案，所有经验恰好归属一次，可保留未分类，不改正文或信用。类别名称/描述可随归属变化更新，沿用有效类别身份时ID保持稳定。

两种更新均有限纠错。格式/结构/输入预算/拒答或请求耗尽保留旧正文/分类，记录错误继续；分类失败队列保留，同一版本不在每题重试。鉴权、配置、存储和程序错误仍fail-fast。held-out禁止归纳/分类；历史证据不自动认证新文本。
