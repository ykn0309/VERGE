# 可靠性与使用记录

当前见[计划65](../plans/65-原子经验类别检索与同判独立记录.md)。保留Beta(1,1)、正负分别累计及confidence=alpha/(alpha+beta)，它是平滑历史应用证据分数，不是已校准的经验有效概率。

P为正确区分标准的归一化额度，N为反向区分额度，多来源均分；alpha+=P、beta+=N，无衰减、不先抵消、不用margin增益。只有P+N>0才追加数值证据。已有经验只从R0累计；候选只使用最终入池轮次信用，不叠加未选候选。

同判不改置信度。独立保存每次应用的positive/negative/both_true/both_false标准次数、sample_id及实际text_version；多来源各记录一次所引用标准，不把计数当作独立任务。区分率=(positive+negative)/全部引用标准数，无引用为未知；它包含反向区分，不代表方向正确率，仅展示，不接入Selector。

例如从(1,1)开始，+0.2更新为(1.2,1)，confidence约54.5%；−0.2更新为(1,1.2)，约45.5%；同时+0.2和−0.2更新为(1.2,1.2)，50%；仅同判保持(1,1)，但对应同判计数增加。选择、召回或仅提供候选不产生信用。

累计强度A=alpha+beta−2，是额度总和而非独立任务数；Selector保留confidence/A作为适用性相近时的参考。类别不拥有信用，不向成员传递置信度。小经验归纳后保留历史信用与实际使用版本，历史累计不自动证明新文本有效；允许Judge噪声，不因一次失败撤销信用或增加语义准入门禁。

正向和反向案例参与延迟归纳，同判不进入；完整轨迹保留。冻结评价不写任何信用、使用、案例、正文或分类。Manifest/Trajectory8、Memory6，旧协议保留文件但不迁移或跨协议resume。
