# VERGE v3.1：聚类修改（暂定）

2026-11-13用户暂定。此前500题实验对应v3；本文记录v3.1的聚类方向，尚未实现或实测，其他模块的修改另行讨论。

## 1. 修改目标

v3按具体对象ID计算关联Jaccard：任务比较提供过哪些经验，经验比较被哪些任务提供过。虽然保存了两侧分组，相似度却不使用对侧类别，不能利用“不同对象属于相近类别”的信息。

v3.1保留文本相似度，将关联部分改为**对侧类别的归一化关联分布相似度**，让两侧分组交替更新。

## 2. 类别关联分布

底层继续保存去重的具体任务—经验提供边，按当前对侧归属汇总：

- 对任务t：统计实际提供过的经验中，各经验类分别有多少条经验。
- 对经验e：统计提供过它的后续独立任务中，各任务类分别有多少道任务。

将各类别计数除以该对象的总关联数，得到分布p：

```text
p_x(g) = x关联到对侧类别g的具体对象数 / x的总关联数
```

每个对象仍只有一个所属类；分布表示它关联了哪些对侧类别，不表示多重归属，也不是收益或适用概率。无关联时分布未知，不构造均匀分布。

随后确认训练最多试用三条经验、每路单独一条，因此每道任务最多形成三条正式提供边。三条已入池经验实际分别提供后，都记录本题关联；这表示同题分别试用，不表示组合有效。任务侧可关联多个经验类，经验侧可关联多个任务类，继续按对侧类别分布比较；来源候选验证仍排除。

## 3. 相似度与交替更新

对同类型对象x、y，用归一化分布计算加权Jaccard：

```text
J_group(x,y) = Σ_g min(p_x(g), p_y(g)) / Σ_g max(p_x(g), p_y(g))
S(x,y) = (1−w) × T(x,y) + w × J_group(x,y)
```

T继续使用文本向量相似度。任一对象没有关联时，仅用T；w的具体取值及证据量如何影响w尚待确定，不把稀疏记录当作充分的不相似证据。

初始化依靠文本，在线更新沿用已有分组；保存新提供边后，按以下顺序交替：

1. 按当前经验类别汇总任务的关联分布，更新任务分组。
2. 按更新后的任务类别汇总经验的关联分布，更新经验分组。
3. 重新汇总，继续交替；整轮归属不变则停止，暂沿用最多5轮，触顶仍变化时记录未稳定。

类别变化后必须更新分布和相关相似度；不能沿用v3中不依赖类别的固定成对分数。该交替过程不保证收敛或全局最优。

## 4. 保留的规则与待验证边界

- 关联仍是后续独立任务实际向Generator提供经验的行为，不依赖自报引用；同题去重，来源验证不给候选建边或记收益。
- 聚类比较使用模式，收益另用于验证和选择；同类不证明有效、可互换或应该合并正文，不自动继承组内其他经验的收益。
- 经验类别通过任务聚类间接参与本次调整；不新增按经验组筛候选或按经验组收益排序的规则。
- 如果对侧全是单成员组，类别汇总不会增加跨对象的共享类别信号，仍需验证文本初始化与分组门槛。
- 新任务尚无提供边，查询历史任务组仍依靠文本；本改动不直接保证查询命中率或最终收益改善。

当前仅暂定上述方法。关联权重、门槛及初始化细节仍待讨论；分组数量减少不等于分组质量或最终偏好判断改善。
