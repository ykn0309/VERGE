# VERGE v3问题与v3.1改进汇总

2026-11-13。汇总用户已确认的暂定方案；v3.1尚未实现或实测。各问题对总体损失的贡献尚未隔离，不能将对应改动视为已证明有效。

## 1. v3暴露的问题与对应改动

v3的500题在线训练观察中，391个有效有／无经验配对有52改善、62退化，未显示净收益。这不是独立泛化测试。依据见[报告120](../实验分析/120-General500题四路流程实测.md)、[聚类审查121](../实验分析/121-500题多成员聚类内容审查.md)、[内容审查122](../实验分析/122-改善与退化114题内容分析.md)。

| v3的问题或风险 | v3.1暂定处理 |
|---|---|
| 聚类比较具体任务／经验ID的关联交集，未利用对侧类别；关联稀疏时可能低估相近程度，分组和历史任务组命中也较稀疏。 | 保留原始提供边，按对侧类别汇总并归一化，用加权Jaccard融合文本相似度，交替更新任务与经验分组，暂沿用最多5轮。 |
| 历史反馈实际参与选择较少，部分经验缺少下游验证。 | 保留程序按聚类和历史效果召回、排序，再由Selector核查适用性的结构；训练平等试用最多3条经验，推理最多选1条，增加逐条验证覆盖。候选继续最多10条，6历史＋4全池语义，缺额由语义补齐。 |
| Critic可能围绕来源题修复，或根据chosen/rejected差异反推出具体甚至错误的要求。 | 加入人工偏好理由，同次调用先核对选择、Rubric设计和Judge执行的文本依据，再决定能否提炼经验；依据不足或只有Judge问题时不生成。人工理由也需核对，受赞写法不能直接变成通用硬要求。 |
| Generator可能将经验变成额外义务，遗漏原要求或改变评价目标。 | 先只看task生成初稿R0，再根据task、R0及该路经验修订；所有路径共享初稿，并各修订一次，无经验路也修订。允许保留或纠正初稿，不把初稿当真值。 |
| 记录了组合效果，但最终选择未学习具体搭配条件；同时存在组合收益和干扰。 | 本版暂缓组合。每路只用一条经验，分别比较其与无经验的结果，不运行组合，不做组合信用分摊或组合选择。 |
| 实际路径失败就触发Critic，即使已有其他成功路径，仍可能继续为本题产生经验。 | 任一路（含无经验）成功就不进入Critic；仅全部已运行路径均明确失败时进入。无经验成功、经验全失败时只记录负收益。 |
| Judge误读、计数或执行错误会污染来源验证和下游反馈。 | Critic可以分析疑似错误，但诊断不是真值；只有Judge问题时不提评分标准经验。Judge误判本身仍未解决，未采用投票、重复评分或自动更正。 |

## 2. 训练与推理

两者的选择主干一致：**程序按聚类与历史效果召回、排序候选 → Selector结合task核查适用性 → Generator → Judge。**

- **程序候选：**最多10条，6条历史收益候选加4条全池语义候选；去重后缺额继续用语义补齐。没有达标任务组时全部走全池语义，历史收益标为未知。
- **训练：**Selector最多选3条，也可少选或不选。E1、E2、E3分别单独使用，加无经验对照，最多四路并行；三条经验平等参与，不划分首选与探索。
- **推理：**Selector最多选1条，也可不选；只执行最终所选路径。程序不替代Selector作最终选择，不设“历史收益必须大于0”的使用门槛。
- **生成：**每题先得到同一初稿，各路径从该初稿出发修订一次；无经验路也按task和初稿修订，再独立Judge两份匿名回答。
- **Critic：**仅所有路径均明确失败时进入；未选经验时，无经验失败仍可冷启动。每轮最多提1条，最多2轮，可以不提。

三条经验的后续信用分别计算：

```text
c(E_i) = r(E_i) − r(∅)
```

r为最终判断与训练标签一致的结果（对1、未判对0）。每条经验与无经验路分别配对；对应路径技术失败时信用未知，不补0，不影响其他有效配对。每题每经验只记一份证据，三路中至少一路成功的覆盖率不等于推理单路准确率。

三条平等试用提高同题可测试的经验数量，不保证每条经验都有足够的独立任务证据。

三条入池经验实际分别提供后，都建立本题的提供关联，同题去重。Critic来源候选验证只决定准入，不记候选信用、不建来源关联；候选仍沿用单条判对准入，入池后继续靠独立任务积累证据。

## 3. 保留的边界

类别关联表示使用模式，不代表适用或有效；文本、Selector选择及收益是不同信息。同类不自动合并正文或继承收益。新任务无关联时仍按文本查询，类别分布也不能凭空解决所有单成员组。

人工理由、Critic诊断、初稿和Judge均可能出错。两阶段生成、更多试用或更少候选都不自动等于改进；来源通过不证明跨任务泛化。聚类权重、门槛、初始化及部分失败处理细节仍需明确，再决定实现和验证。
